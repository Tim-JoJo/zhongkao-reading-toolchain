# 固定输出合同

除非用户明确要求简版，按下列顺序交付。

## 1. 任务配置

- 档位：`standard | extended`
- 原文标题、来源、日期、链接；缺失项写"未提供"
- 主题范畴和语篇类型
- 材料准入结论：`适合 / 调整后适合 / 不适合`

## 2. 正文

给出标题和完整英文正文。不要在正文中插入分析标签。

## 3. 指标报告

| 指标 | 实际值 | 档位目标 | 状态 | 说明 |
|---|---:|---:|---|---|
| 正文词数 |  | ≤350 词 | 通过/需复核 |  |
| 平均句长 |  |  | 通过/需复核 |  |
| 句长 P90 |  |  | 通过/需复核 |  |
| 词表覆盖率 |  | 九年级 95%–97% | 通过/需复核 |  |
| 超纲词比例 |  | 九年级 3%–5%（按唯一词元计） | 通过/需复核 |  |
| 长难句 |  | 2–4 句，≥2 段，≥2 种类型 | 通过/需复核 | 列出每句及类型 |
| 生词注释 |  | 带中文注释的超纲词 = 超纲词总数（唯一词元）的 50%–60% | 通过/需复核 | 列出词及注释；同一词族只注释首次出现的词 |

全部指标数据来自 `mcp__zhongkao-mcp__check_passage`（组合 vocab-checker 词汇检查 + 篇幅/句长/专名分析），数据源唯一，不存在交叉不一致。

若无法运行任一工具，明确标为"未自动核验"，不要估算成已通过。

### 3.1 年级合规

单独列出年级层面的四项检查（覆盖率、超纲词数、专名数、平均句长）及其通过状态。数据来源同上，来自 `check_passage` 返回的 `grade_check` 字段。

### 3.2 段落词数检查

逐段统计正文的段落词数，格式如下：

| 段落 | 词数 | 功能 | 状态 |
|---|---:|---|---|
| Para 1 |  | 引入主题 | ≤90 / 超标 |
| Para 2 |  | 展开细节 | ≤90 / 超标 |
| ... |  |  |  |
| 全文合计 |  | — | ≤350 / 超标 |

**阈值：每段不超过 90 词，全文不超过 350 词**。超标段需压缩或拆分。此检查在 `check_passage` 整体指标通过后执行，作为段落层面的细粒度校验。

## 4. 写作说明

### 事实骨架

列出必须保留的事实、研究结果、专家观点和作者判断，并给出来源句编号。

### 主要操作

说明行文逻辑模块选择、事实编排、词汇降级、句法处理、段落组织和必要连接。

### 词表外词

| 词元 | 保留理由 | 语境线索/注释 |
|---|---|---|

## 5. 质量检查

分三类报告：

- 严重项：全部通过后才能交付
- 工程带宽：通过或需复核
- Humanizer：宣传、万能升华、套式比喻、同义轮换、机械节奏、虚构细节
- 地道性：无伪简单搭配、直译式组合或为了覆盖率而降低专业准确度

最终状态只能是：

- `可交付`
- `需人工复核`，并列出具体问题
- `不适合`，并说明理由
