# 两档批准标准

这些数值是根据课程标准和七地真题样本制定的工程标准，不冒充课标原文。

| 项目 | 标准档 | 拓展档 |
|---|---|---|
| 课标定位 | 三级 | 三级+ |
| 参考地区 | 河北、山东中高难度 | 北京高难度 |
| 建议篇幅 | 全文 ≤350 词，由段落数和每段 ≤90 词自然决定 | 全文 ≤350 词，由段落数和每段 ≤90 词自然决定 |
| 平均句长 | 13—15 词 | 16—18 词 |
| 句长 P90 | 不高于 24 词 | 不高于 30 词 |
| 超长句预警 | 超过 32 词复核 | 超过 38 词复核 |
| 主体词汇 | 二级＋三级词表 | 二级＋三级词表，受控增加主题词 |
| 词表覆盖率 | 正文唯一词元覆盖率 95%–97%（按唯一词元计） | 正文唯一词元覆盖率 95%–97%（按唯一词元计） |
| 超纲词比例 | 3%–5%（与覆盖率区间互补；同一生词反复出现只计一次） | 同左 |
| 词表外主题词 | 不设硬性上限，逐词登记保留理由 | 不设硬性上限，逐词登记保留理由 |
| 语篇类型 | 记叙、说明、应用、新闻、新媒体 | 前述类型＋简单说理 |
| 信息关系 | 清晰因果、转折、比较、举例 | 可保留多层因果和观点—证据—结论 |
| 推理跨度 | 相邻句或同段跨句 | 跨段、作者观点、论证作用 |
| 生词处理 | 优先替换；必要术语可推断或注释 | 允许少量关键概念，须有上下文支撑 |
| 专名处理 | **专名默认保留，不做泛化。无数量限制。** | **专名默认保留，不做泛化。无数量限制。** |
| 段落词数 | **每段不超过 90 词** | **每段不超过 90 词** |
| 全文词数 | **全文不超过 350 词** | **全文不超过 350 词** |

## 统计口径

- 正文词数不计标题、题干、选项和中文注释。
- 词表覆盖率和超纲词比例均基于**唯一词元**计算：同一词反复出现只计一次；排除标点、纯数字和已登记专名；先做大小写、词形和变体归一化。
- 词表外不同词元合并常见屈折变化；每个保留词登记理由。
- 专名统计的是需要建立指代或记忆关系的人名、机构、地点、产品、项目等不同实体。
- 同一实体的全称、简称、别称和重复出现合并为 1 个。

## 带宽如何使用

- 专名不设数量带宽，每个保留的专名只需标注信息功能（真实性、来源可信度、人物区分、文化身份、比较对象、题目证据）。
- 超出篇幅、句长或覆盖率带宽时进入"需复核"，不是自动失败。
- 例外必须说明它如何服务事实精度、文化身份、来源可信度、比较关系、观点归属或题目证据。
- 不得为达到数字而删除关键事实、改变证据类型或制造低频同义词。
