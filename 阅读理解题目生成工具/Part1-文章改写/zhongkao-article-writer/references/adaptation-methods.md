# 写作方法

## 1. 词汇层面

替换目标是降低不必要负担，不是制造表面同义。每次替换检查事实范围、语气强度和专业精度。

### 地道性门槛

降级后的表达必须是自然英语，不只是由简单词拼成的可猜短语。

| 不采用 | 推荐 |
|---|---|
| `computer pictures` | `computer vision`，必要时解释为 technology that helps a computer see |
| `picture programs` | `AI programs / algorithms`，必要时注释 |
| `light parts` | `optical parts / parts that use light` |
| `at a slow speed and with care` | `slowly and carefully` |
| `several people from universities` | 原文支持复数时用 `experts / scholars` |
| `creative power joins experiences` | `creativity grows from experience and new ideas` |
| `AI-made summary` | `AI summary / summary made by AI` |

如果自然表达不在主体词表中，优先保留并提供语境或注释，不要用失真、幼稚或不地道的组合换取覆盖率。

| 原表达 | 建议表达 | 方法 | 不能直接替换的情形 |
|---|---|---|---|
| align with | agree with / follow | 抽象动词降级 | 技术或几何“对齐” |
| ramifications | serious results / effects | 抽象名词降级 | 必须保留负面方向 |
| hinder | limit / make it hard for | 动词或短语降级 | `limit` 弱于 `prevent` |
| self-sabotage | actions that make things worse for oneself | 释义 | 不能改成 `self-doubt` |
| aspiration | hope / goal | 同义降级 | 按愿望或目标选择 |
| cognitive-behavioral techniques | ways to change thoughts and behaviors | 去术语＋释义 | 疗法本身是全文核心 |
| facilitate | help / make ... easier | 动词降级 | 不能写成“导致” |
| compassion | kindness and understanding | 释义 | `sympathy` 可能过窄 |
| acknowledge | admit / recognize | 按语境选择 | 承认错误与认识事实不同 |
| prevalent | common | 同义降级 | 医学患病率语境 |
| synthetic polymers | man-made materials | 上位概括 | 材料种类是机制或考点 |
| disintegrate | break down | 短语降级 | `disappear` 可能丢失分解机制 |
| hazardous | dangerous | 同义降级 | 法规或化学危险等级 |
| envision | expect / hope | 按确定性选择 | 预测与愿望不能互换 |
| biodegradable | able to break down naturally | 定义性释义 | 核心关键词可保留并解释 |
| accountability | responsibility | 同义降级 | 法律问责语境 |
| evaluate | study / check / judge | 按对象选择 | `judge` 语气更强 |
| detect | find / discover | 近义降级 | 设备检测机制需要精度 |
| habitat | living space / place where ... lives | 释义 | 生态文章可保留并解释 |
| accuracy rate | how often it works correctly | 释义 | 数据或考点可保留并注释 |
| spinal cord injury | damage to the spinal cord | 核心术语＋释义 | 不能泛化为普通身体受伤 |
| paralyzed | unable to move parts of the body | 释义 | 不能直接写 `disabled` |
| approximately | about | 同义降级 | 仍须保留“约数” |
| nevertheless | however / still | 连接词降级 | 逻辑强度和位置要正确 |
| the preservation of | protect / protecting | 名词转动词 | 施事者不能消失 |

### 必须保留或解释的词

满足任一条件时，不要强行换成不准确的高频词：

- 全文核心科学或文化概念
- 无准确高频替代
- 题目考点
- 事实精度依赖该词

处理方式依次选择：

1. 原词＋中文注释
2. 原词＋英文同位解释
3. 前后文定义、例证、同义或反义线索
4. 构词法线索

## 2. 语法与句法层面

| 结构 | 方法 | 标准档 | 拓展档 | 风险 |
|---|---|---|---|---|
| 连续前置修饰的长名词组 | 拆成主谓或介词短语 | 优先拆 | 可留一层必要修饰 | 对象范围不能收窄 |
| 多层定语从句 | 保留核心限定，其余拆句 | 通常拆 | 可留单层关系从句 | 先行项要明确 |
| 连续非谓语 | 改为有限动词和显性关系 | 优先显化 | 保留短而熟悉的结构 | 不得新增因果 |
| 分词状语 | 改主句或明确从句 | 按需拆 | 可留常见结构 | 分词主体必须一致 |
| 被动语态 | 施事者清楚时可改主动 | 能改则改 | 科技报道可留必要被动 | 未知施事者时不强改 |
| 名词化 | 改成动词 | 优先 | 论证语体可留少量 | 责任主体不能消失 |
| 人物同位语 | 留与理解有关的一个身份 | 压缩 | 可留简短专业身份 | 身份决定权威时不能全删 |
| 插入引语 | 移句首/句末或改间接引语 | 优先重组 | 可留简短 `said X` | 非逐字不能放引号 |
| 三项以上并列 | 留代表性项目或分句 | 控制密度 | 可留与论证相关的并列 | 删项不能改范围 |
| 多重从属 | 先拆主干，再留关键从句 | 最多 1—2 层 | 可留 2 层但避免连续 | 条件、让步、转折不能互换 |
| 长原因句 | 原因和结果分开 | 优先拆 | 可留单层 | 相关性不能写成因果 |
| 指代链过长 | 恢复关键名词或缩短距离 | 优先澄清 | 可保留清晰可考指代 | 不要消除全部指代 |
| 新闻式省略 | 补全主语、谓语或介词 | 补全 | 可留常见省略 | 时态和时间须一致 |
| 双重否定 | 改直接肯定 | 优先 | 必要语气可留 | 语气强度可能变化 |
| 强调或倒装 | 改正常语序 | 优先 | 可少量保留 | 强调焦点不能丢失 |
| 复杂条件或虚拟 | 改真实条件或分句解释 | 降阶 | 可留常见 `if` | 反事实不能改成真实可能 |

目标是降低嵌套、信息负荷和指代距离，不是把文章全部改成短句。保留自然长短句变化。

## 3. 语篇层面

### 事实骨架

先列人物、时间、地点、行为、数据、过程和结果；每项标来源句。

### 主线选择

- 标准档：一条核心问题或事件主线，例证通常 1—2 个。
- 拓展档：可保留一条次线，例证通常 2—3 个。
- 专业机制至少保留“输入—过程—结果”；拓展档可多一层限制或条件。

### 段落重组

允许把分散的同功能信息合并，但合并后逐项回挂原文，防止拼出新因果。

**推荐语篇结构模式：**

| 模式 | 段落数 | 适用体裁 | 结构说明 |
|------|--------|---------|---------|
| 总分总 | 3 – 5 段 | 说明文、新闻报道 | 首段引入主题 → 中间段展开 → 末段总结 |
| 起承转合 | 4 段 | 新闻、叙事 | 起（引入）→ 承（展开）→ 转（应对/分析）→ 合（收束） |

**常见体裁的内在结构：**

- 记叙：背景—触发—行动—结果—认识
- 科普：问题—机制—测试—应用—限制
- 新闻：现象—事实—例证—影响
- 简单说理：观点—证据—反面或限制—结论

### 数据与例证

- 标准档通常保留 1—3 组关键数据。
- 拓展档可保留更多，但每组必须说明规模、变化、效果或限制。
- 不改数字；近似值用 `about / nearly / more than` 保持精度。
- 多个同类例子只保留最易懂且最能支撑主线或题目的例子。

### 开头与结尾

- 原文开头成人化、网页化或过密时，可用原文核心现象或问题导入。
- 不用虚构人物故事制造亲近感。
- 删除营销、免责声明和无关行动号召。
- 结尾落在原文已有的结果、限制、计划或现实意义；不补“光明未来”“改变世界”等万能升华。

## 4. 逻辑层面

### 必须保留

- 因果方向
- 事件时间顺序
- 比较对象和比较维度
- 观点、证据和结论的归属
- `some / many / all` 等范围
- `may / could / will` 等确定性
- `one study / studies` 等证据数量
- `almost / more than / at least` 等数字边界

### 可以显化

原文关系明确但表达隐含时，标准档可用 `because / so / as a result / however` 显化。先在证据账本中写出支持两端，再添加连接词。

### 不能显化

- 时间先后不等于因果
- 同段共现不等于相关
- 作者推测不等于研究结果
- 一位专家的意见不等于领域共识
- 潜在用途不等于已经实现

## 5. 专名与引述

| 原始来源 | 可用改写 | 适用条件 | 风险 |
|---|---|---|---|
| `Professor Smith says` | 保留姓名或 `An expert says` | 一名专家 | 不能写 `Experts say` |
| 多位专家同一判断 | `Experts say` | 原文确有多人且可共同概括 | 有分歧时不能合并 |
| `A study found` | `A study found/shows` | 单项研究 | 不能写 `Studies show` |
| 多个独立研究 | `Studies show` | 原文明确支持复数 | `research` 不自动等于多项研究 |
| 具名研究团队 | `Researchers / a research team` | 机构身份不影响理解 | 合作关系或来源核验重要时保留 |
| 两个团队合作 | `Two researchers/teams worked together` | 合作是主线 | 不能压成 `one team` |
| 权威机构 | 保留简称或上位身份 | 根据权威性和负担选择 | 数据依赖权威来源时优先保留 |
| 具体公司 | `a company` | 公司名与题意无关 | 不无依据增加 `famous` |
| 具体产品 | 保留名或 `the/another device` | 比较身份清楚 | 不能把竞品名换成另一个产品 |
| 直接引语 | 间接引语 | 非逐字改写 | 不能把概括句放进引号 |
| 专业身份 | `a scientist / an engineer` | 专业细分不影响理解 | 身份决定分工或权威时至少留上位身份 |

## 6. Humanizer 受控清单

### 删除或改写

- `stands as / serves as a testament / marks a pivotal moment`
- 无依据的 `important / valuable / promising / safer / effective`
- `The real question is / at its core / what really matters`
- `A summary shows the road; readers take the journey` 一类套式比喻
- 三句连续短促结论或机械三点式
- `highlighting / ensuring / reflecting` 等尾接式假分析
- 为避免重复而把同一概念轮换成多个近义词
- “未来一片光明”“迈出重要一步”等通用正向结尾

### 保留

- 具体而可核验的细节
- 原文真实的矛盾、限制和不确定性
- 必要的术语重复
- 自然的长短句变化
- 报道、科普、记叙各自应有的中性或具体语体

### 最终两问

1. 哪些句子像模型为“完整、深刻、顺滑”而补出的？
2. 是否新增了原文没有的事实、名称、数字、日期、引语、因果或评价？

再加一问：是否有任何句子“每个词都简单”，但整体不像自然英语？若有，恢复自然搭配，并把必要词登记为主题词。

发现新增即删除或恢复为原文支持的较弱表达。
