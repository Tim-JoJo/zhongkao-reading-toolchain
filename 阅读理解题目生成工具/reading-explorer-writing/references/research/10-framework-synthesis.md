## 一、领域共识框架(24 篇共通,三重验证)

### C1 引而不答的设问
- **一句话**:问句不是修辞,是结构承诺——读者知道后面必有答案,所以往下读。
- **证据**:24 篇中 13+ 篇以问句开场或作小标题;1A "How?" 承诺后由三个小标题逐一兑现;4A 每段末问句作路标;7A 问句小标题;7B 极短悬问 "Whose hand is this?" 四个词即钩子。
- **生成力**:可推断——新素材无论主题,都可提炼一个"读者心里有过但没人说破"的问题作导语。
- **排他性**:区别于"设问作为修辞点缀"——这里是结构骨架,答案顺序即承诺顺序。
- **局限**:问题必须读者真的想知道答案,否则是白问。

### C2 可成像的细节优先
- **一句话**:画面+动作代替抽象论证,用"后果/流程"代替机制本身。
- **证据**:11A 拔 10 厘米吸管(场景)vs 81 亿公斤(数据);2B 头朝下坠落流程 vs "危险"形容词;1B 卷成球像岩石(后果)而非讲肌肉原理;9B 体重区间 120–200 磅(荒谬细节)。
- **生成力**:任何抽象结论都可问一句"读者脑中能出现什么画面?"。
- **排他性**:教材体系的核心信仰——"孩子记不住概念,但记得住画面"。
- **局限**:纯思辨主题(4A 外星生命)靠数字规模与时间期限落地,强造具象会降格。

### C3 确定性梯度管理
- **一句话**:作者敢给倾向,但永远用梯度词标注可信度(without a doubt > likely > perhaps/might)。
- **证据**:12B 全篇按确定性排序四种理论;4A "believe/probably/might" 单边论证不越界;7A 推翻有把握的、保留未定的。
- **生成力**:对任何未定论问题,可按梯度排序而非二值判断。
- **排他性**:把"诚实"写进句式,既引导读者又训练怀疑。
- **局限**:过度 hedge 会泄气;断言型文本(1B 章鱼机制)不需要。

### C4 导语五秒钩子
- **一句话**:开场决定去留;钩子类型可枚举——设问、场景、名言、数据、镜像现象。
- **证据**:11A 疼痛场景;4B 霍金名言;12B "最后一天"直播式叙事;5B 镜像味觉谜题;10B 括号幽默否定式设问。
- **生成力**:写任何导语前先问"这五秒凭什么留住人"。
- **局限**:访谈体/传记体导语可例外(文体契约不同)。

### C5 信源分工
- **一句话**:专家/引语不是装饰,按功能分配——体验型/定性型/前瞻型。
- **证据**:11A 三处引语分别讲感受/定性/前瞻;10B 骨骼专家讲身体、考古学家讲意义;6A 权威讲意义、实践者讲体验;12A 信源与证据合一(亲历者讲自己发现的事)。
- **生成力**:安排引语前先问"这条引语承担什么功能,不重复吗?"。
- **局限**:引语额度只有一句时,留给情感而非信息(7B、12B、9B)。

### C6 结尾不总结,只升级
- **一句话**:结尾不回头总结(泄气),用画面/预测/引语/意义/静止快照收束。
- **证据**:1A 停在最强例子的画面;4A 带期限的预测;12B 墓志铭式引语;10B 引语把事实改写成史诗;2B 静态快照;11B 停在最后一条的动作。
- **生成力**:写结尾前问"总结 vs 升级——读者带走的是回顾还是未来"。
- **局限**:清单文/学术文可接受总结(3B 总括升华),但那是明确的选择。

### C7 数据挂靠场景
- **一句话**:数字必须挂回可感知的画面或场景,否则无重量。
- **证据**:11A "那只海龟只是 700 种之一";11B 数据是每条建议的信用背书;6A "30 厘米盒子里 600 种生物"(小载体×大发现)。
- **生成力**:写数据前问"这个数字挂在哪幅画面上"。
- **局限**:纯数据文章(5A 榜单)由图表承载,正文解读趋势即可。

### C8 篇幅即立场
- **一句话**:观点不靠形容词表达,靠篇幅、位置、顺序。
- **证据**:4B 正方两段反方一段,用篇幅差表态;5B 镜像两半信息密度完全相等。
- **生成力**:写争议主题时,先设计"天平"再动笔。
- **局限**:简单立场文章不需要;过度端平会显得骑墙。

### C9 直引/转引分工律
- **一句话**:专家越权威,越用转述;直接引语留给"数据/情感/观念/史诗/从业者自评"。
- **证据**:3A/3B 具名专家最多却零直接引语(全转述);4A 唯一引语是数据(带省略号截取);7B 唯一引语是情感;10B 引语分工"骨骼专家讲身体、考古学家讲意义";12B 两句引语框全文(现场实录+墓志铭)。
- **生成力**:安排引语前先问"这条引语承载什么非技术功能";技术内容一律转述。
- **排他性**:把引语当"最贵的信源"而非装饰。
- **局限**:访谈体(6B/9A)自述无引号;虚构叙事(8B)是唯一允许对话的文体。

### C10 非正文装置分流
- **一句话**:凡"读者想知道但会打断主线"的内容,放框/脚注/图注,不占正文。
- **证据**:生词→脚注(1A);可操作数据→播放列表(3A);案例/硬数据→图注框(6A/7A/10A);证据结构→加粗标签(12A)。
- **生成力**:正文里出现"这个数据很有趣但会岔开"时,问"能不能剥出去"。
- **局限**:框太多会切碎阅读;核心证据仍须在正文。

### C11 结尾分层(情感闭环+未闭合未来)
- **一句话**:收尾分两层——先给情感闭环,再给未闭合的信息。
- **证据**:11A 海龟放归在 D 段(闭环),E 段只 2 句以新增量收尾;12B 墓志铭引语后谜团仍无解。
- **生成力**:读者需要"情绪落地",但文章可以保留"问题未了"。
- **局限**:适合悬案/问题类主题;清单文/结论文不需要。

### C12 确定性衰减
- **一句话**:确定性最高的词放开头定调,梯度词沿文越到结尾越弱。
- **证据**:12B "without a doubt"在第一段,到结尾只剩"seems most likely";7A 推翻有把握的、保留未定的。
- **生成力**:用词位置本身就是叙事节奏——开头断言抓人,结尾谦逊留余地。
- **局限**:只适用"结论无定论"的题材;笃定型文本(1B)不需要。

## 二、流派分歧(8 种行文逻辑,见 01-module-library.md 详述)

1. **悬问驱动型**(1A/3A/3B/4A):设问承诺→并列答案逐段兑现→最强留最后
2. **现象—机制—成因型**(1B/6A/7A):现象画面→机制后果→成因情感反转
3. **解谜推理型**(7B/12A/12B/10B):极短悬问→证据天平→"最可能"→人情收尾
4. **正反对照论证型**(4B/5B):两面等量→篇幅表态→让步断言收束
5. **总分列举清单型**(2B/5A/11B):总起数量→条目微结构均衡→停在最后一条
6. **叙事传记型**(2A/8A/8B):时间线/物件系统→主人公自己发声→结尾可带走道理
7. **访谈问答型**(6B/9A):问题递进→数据嵌答案→意义问题收尾
8. **场景开篇问题放大型**(11A/9B/10A):疼的场景→放大数据→数据回扣场景→未来画面

## 三、决策启发式(素材→选模块,诊断顺序自上而下命中即停)

| # | 规则(如果...) | 命中模块 |
|---|---|---|
| H1 | 素材是采访/问答稿,有受访者 | 七·访谈问答 |
| H2 | 素材天然是 N 个并列条目 | 五·总分列举 |
| H3 | 有两派对立观点或两个镜像样本 | 四·正反对照 |
| H4 | 有完整故事弧线(人物/事件/时间线) | 六·叙事传记 |
| H5 | 有未解之谜/悬案,能摆正反证据 | 三·解谜推理 |
| H6 | 能抓住一个"疼/具体"的场景 | 八·场景开篇放大 |
| H7 | 能拆出"现象→机制→成因"三层 | 二·现象机制成因 |
| H8 | 以上都不明显→提炼核心问题+2-4 并列答案 | 一·悬问驱动 |

**局部启发式(模块内选型)**:
- H9 导语:素材有名人→名言开场(4B);有疼痛画面→场景开场(11A);有悬念→极短设问(7B);是已知人物的未知结局→直播式叙事(12B)
- H10 数据:目标是让读者行动→数据收窄到个人层("你明天就能做")
- H11 直接引语:额度只有一句→留给"被写的人自己说"或"情感"(12B 墓志铭、9B 从业者);技术内容一律转述(C9)
- H12 结尾:无解的谜→情感闭环+未闭合未来分层(11A/12B);清晰结论→预测/画面(4A);行动建议→停在最后一条(11B)
- H13 无定论→确定性梯度词排序,不盖章;有定论→笃定陈述不加 hedge(1B)
- H14 第二人称:目标让读者"做/参与"→开 you/we 视角(11B/3A/6B);知识/叙事型→保持第三人称旁观(10B/12B/4B)
- H15 旁数据:生词→脚注;可操作数据→列表/框;打断主线硬数据→图注框;证据结构→加粗标签(C10)

## 四、反模式(绝不做,来自逐篇"常见坑"归纳)

| # | 反模式 | 正确做法 |
|---|---|---|
| A1 | 导语堆数据 | 场景/设问/名言先行,数据后置并挂靠场景 |
| A2 | 承诺 3 个答案只给 2 个 | 承诺数量=正文段落数,逐段显式兑现 |
| A3 | 结尾总结 | 升级:画面/预测/引语/意义/静止快照 |
| A4 | 分论点篇幅不均 | 每条目固定微结构、等量信息密度 |
| A5 | 抽象形容词代替画面 | 用动作/流程/后果/荒谬细节 |
| A6 | 悬案硬给绝对答案 | 给"最可能"+ 梯度词,诚实保留开放 |
| A7 | 直接引语只讲信息 | 至少留一句给情感/意义/被写的人自己说 |
| A8 | 反方写成稻草人 | 反方也要真凭实据,否则论点廉价 |
| A9 | 设问读者不关心 | 问题必须是读者心里有过、没人说破的 |
| A10 | 清单文强行升华 | 停在最后一条的动作,不喊口号 |
| A11 | 虚构叙事物件无功能 | 物件必须承前启后(钥匙→门→认亲) |
| A12 | 敏感文化话题猎奇化 | 尊重、不评判,把镜头对准传统与勇气 |
| A13 | 引语只讲信息不讲人性 | 越学术越转述;直引留给数据/情感/观念/史诗/自评(C9) |
| A14 | 知识/叙事文章滥用第二人称 | 你/we 是"行动/参与"型专用视角;旁观型文章保持第三人称(H14) |
| A15 | 旁数据塞进正文打断主线 | 按 C10 分流:脚注/列表/图注框/证据标签 |
| A16 | 结尾只给信息不给情绪落地 | 先情感闭环再未闭合未来(C11);或一句引语收束 |

## 五、核心张力(主题的内在矛盾,深度的来源)

1. **教与诱**:教材要教阅读技能(结构清晰可预测),又要有杂志的吸引力(钩子、悬念)——于是"设问承诺+逐段兑现"成了两者共生的最优解。
2. **确定性 vs 好奇心**:要教"如何判断确定度"(12B 配套技能),又要保住悬念——于是"给最可能但不盖章"成了标准姿态。
3. **简化 vs 诚实**:面向青少年要简化,但悬案、无定论、代价(危险、女工更苦)不能回避——于是"保留开放性+诚实标注"比强给答案更受推崇。

## 六、智识谱系(这套手法的思想位置)

- **影响来源**:新闻特写(news feature)的"场景开篇、引语分工、数据挂靠"、通俗科普(popular science)的"机制揭秘、确定性梯度"、旅行杂志的"猎奇+尊重"、文学童话的"物件系统+团圆收尾"。
- **影响去向**:外刊改编、中高考英语阅读命题、教材体英语写作——即用户的项目核心。
- **位置**:介于"硬新闻倒金字塔"与"纯文学叙事"之间的教材体说明/特写文——既要信息密度又要可读性,所有技巧都服务于"让 12-16 岁读者读得下去且记得住"。
