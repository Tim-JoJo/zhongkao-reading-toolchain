## 执行规则（最重要）

**此Skill激活后，按以下流程执行。不同场景走不同路径。**

### 场景A: 给素材 → 写/改编阅读文章

```
Step 1: 诊断素材特征
  → 通读素材,按诊断表自上而下匹配行文逻辑模块:
    (1) 采访/问答稿有受访者 → 七·访谈问答
    (2) N个并列条目 → 五·总分列举
    (3) 两派对立观点/两个镜像样本 → 四·正反对照(含 L2 辩论体/纠偏式变体)
    (4) 完整故事弧线 → 六·叙事传记(含 L2 第一人称特写变体)
    (5) 未解之谜/悬案可摆正反证据 → 三·解谜推理(含 L2 证据升级变体)
    (6) 有"疼/具体"场景可开场 → 八·场景开篇放大
    (7) 可拆"现象→机制→成因"三层 → 二·现象机制成因
    (8) 以上皆无 → 一·悬问驱动(提炼核心问题+2-4并列答案)
  → 同时决定辅助模块(开场用八/一、中段用并列/递进/对仗/天平/问答/时间线、结尾用预测/引语/画面)
  → 正文超 3 段且多主题 → 用小节标题分区(H16/C13);探险/研究题材 → 数据做记忆锚点(H10/C14)
  → 多模块冲突裁决:选"最能放大素材亮点"的作主模块,其余作辅助;仍难定→询问用户偏好
  → 【检查点】两模式二选一:
      - 快速模式(用户未要求确认,或素材方向明确):直接给"主模块+辅助+理由"一行,不等确认,继续 Step 2
      - 确认模式(素材敏感/方向不确定/用户明说"先给我看看方案"):停下,展示诊断+骨架,等用户确认或改向后再写

Step 2: 搭骨架
  → 打开 module-library.md 对应模块,套用结构骨架
  → 逐段标功能(导语钩子/分论点/证据/收尾),每段落一个"意图"

Step 3: 撰写全文
  → 每段按"意图"填充素材
  → 强制跑共识模型:设问承诺要兑现、细节要可成像、数据要挂场景、引语要分工、结尾要升级不总结
  → 全程过反模式清单(mental-models-heuristics.md)

Step 4: 自检交付
  → 【检查点】交付时附一句"用了哪个模块+为什么",并列出 2-3 个可选改向(换模块/换开场/换结尾)
  → 如需命题合规,提醒用户用 vocab-checker / zhongkao-mcp 校验词汇与篇幅
```

### 场景B: 分析一篇的写法/行文逻辑

```
Step 1: 读文章,六维框架逐维分析:
  ① 整体结构模型与信息流推进方式
  ② 导语切入点与5W1H取舍
  ③ 信源、引语与事实编织手法
  ④ 用词、视角与倾向性控制
  ⑤ 驱动文章的价值元素与读者预设
  ⑥ 场景细节、对比与结尾叙事技巧
  → 每维列具体观察 + 可模仿技巧

Step 2: 归类
  → 对照 module-library.md 判断命中哪个主模块(可命中多模块=杂交)
  → 说明主模块依据:哪几个信号特征匹配

Step 3: 提炼方法论核心
  → 一段话总结"最值得学习的写作方法论核心"
  → 【检查点】输出结构:六维逐条 + 归类 + 方法论核心。用户可要求只给其中一部分
```

### 场景C: 审阅/改写已有稿子

```
Step 1: 通读,定位问题
  → 用反模式清单逐项过(A1-A20),标记命中的
  → 用共识模型检查:设问是否兑现/细节是否可成像/数据是否挂场景/结尾是否升级/长文是否分区

Step 2: 给出诊断
  → 【检查点】先列问题清单(每条:位置+问题+改法),用户确认要改哪些

Step 3: 改写
  → 只改用户确认的问题,不重写全文
  → 保留原作者风格,除非用户要求换模块
```

## 🛑 STOP · 关键 CHECKPOINT

### 场景 A · 动笔前必答 3 问
1. **主模块选对了吗**（对照诊断表,不是凭感觉）?说不出依据 = 重新诊断
2. **导语钩子是什么**（设问/场景/名言/数据/镜像）?没有 = 读者不会往下读
3. **结尾是"升级"还是"总结"**（画面/预测/引语/意义 vs 回头总结）?总结 = 泄气

### 场景 B · 出分析前必答 2 问
1. **六个维度都覆盖了吗**?漏维 = 分析不完整
2. **归类挂证据了吗**?「悬问驱动」要指出"哪句设问、哪段兑现"

### 场景 C · 改写前必答 2 问
1. **先给诊断后改写了吗**?用户没确认问题清单 = 别动笔
2. **反模式对照了吗**?至少把 A1-A20 过一遍

任一答「否」→ 回到对应 Step。

## 失败模式与 Fallback 树

| # | 触发信号 | 第一选择 | 备用 |
|---|---------|---------|------|
| 1 | 素材太泛("写篇文章") | 反问:素材源?目标读者/年级?用途(阅读题/范文)? | 按默认:成人向教材体说明文,再让用户调 |
| 2 | 素材同时命中多个模块 | 选"最能放大素材亮点"的作主模块,其余作辅助 | 让用户选,展示每种组合的开场差异 |
| 3 | 素材没有明显特征(难归类) | 落回模块一(悬问驱动),提炼核心问题 | 用模块八(场景开篇)硬造一个开场画面 |
| 4 | 素材信息不足(缺数据/缺引语) | 用可成像细节+流程代替数字;不硬编引语 | 明说"这篇缺 X",建议补素材 |
| 5 | 用户要严格命题合规(中考词汇) | 出稿后提示调 vocab-checker 校验,不自行承诺达标 | 写稿时就按"短句+高频词"约束 |
| 6 | 敏感文化话题(宗教/民族/政治) | 尊重、不猎奇,镜头对准传统与勇气(同 2B 姿态) | 回避争议细节,聚焦普遍价值 |
| 7 | 用户说"太长/太短" | 教材体参考篇幅:Level 1 正文 250-400 词、段落 4-6 段;Level 2 正文 300-450 词、段落 4-8 段(可带小节标题) | 按目标年级微调句长与词汇 |
| 8 | 素材是图片/PDF/网页链接(非文本) | 用 `mineru-open-mcp__parse_documents` 解析成文本再进诊断;该 MCP 不可用 → 请用户直接贴文本 | 解析后信息仍不全 → 按 #4 处理:可成像细节代替数字、不硬编引语 |
| 9 | 素材是中文/中英混合,目标为英文教材体 | 先提炼素材信息要点(事实/引语/数据),按模块骨架重写成英文,不逐句直译 | 用户要中文教材体 → 保留中文按骨架组织;坚持全英文 → 问清是否先翻译素材 |

## 反例黑名单(绝不要做)

| # | 反模式 | 为什么禁 | 正确做法 |
|---|--------|----------|----------|
| A1 | 导语堆数据 | 读者还没共情就淹在数字里,直接划走 | 场景/设问/名言先行,数据后置挂场景 |
| A2 | 承诺 3 个答案只给 2 个 | 违约 = 信任崩塌 | 承诺数量 = 正文段落数,逐段显式兑现 |
| A3 | 结尾总结 | 读者刚读完就要他回顾,泄气 | 升级:画面/预测/引语/意义/静止快照 |
| A4 | 分论点篇幅不均 | 读者能感觉出作者偏心 | 每条目固定微结构、等量信息密度 |
| A5 | 抽象形容词代替画面 | "危险"不让人发紧,"头朝下坠落"让人发紧 | 用动作/流程/后果/荒谬细节 |
| A6 | 悬案硬给绝对答案 | 没定论的事盖章 = 不诚实 | 给"最可能"+ 梯度词,保留开放 |
| A7 | 直接引语只讲信息 | 引语是最高贵的信源,浪费在信息上 | 至少留一句给情感/意义/本人自己说 |
| A8 | 反方写成稻草人 | 反方没实据,正方也显得廉价 | 反方给真凭实据,天平端平 |
| A9 | 设问读者不关心 | 白问,读者无感 | 问题必须是读者心里有过、没人说破的 |
| A10 | 清单文强行升华 | 读者要的是"做完",不是口号 | 停在最后一条的动作,不喊口号 |
| A11 | 虚构叙事物件无功能 | 道具不承前启后 = 装饰 | 物件必须串情节(钥匙→门→认亲) |
| A12 | 敏感话题猎奇化 | 消费苦难/异文化 | 尊重、不评判,聚焦勇气与传统 |
| A13 | 引语只讲信息不讲人性 | 引语是最高贵的信源,浪费在技术上 | 越学术越转述;直引留给数据/情感/观念/史诗/自评 |
| A14 | 知识/叙事文章滥用第二人称 | you/we 是"行动/参与"型专用视角 | 旁观型文章保持第三人称(10B/12B/4B) |
| A15 | 旁数据塞进正文打断主线 | 读者想知道但会岔开 | 分流:脚注/列表/图注框/证据标签 |
| A16 | 结尾只给信息不给情绪落地 | 读者带着冷数据离开 | 先情感闭环再未闭合未来;或一句引语收束 |
| A17 | 长文无小节标题 | 超 3 段且多主题仍一段段平推,读者迷失 | 用小节标题分区(节标题即承诺,替代段内设问) |
| A18 | 数据堆砌无锚点 | 数字孤零零无记忆点,与场景脱节 | 数据一组化、可记忆(56人/5吨/2197米),挂靠场景 |
| A19 | 引语只讲信息不落情怀 | Level 2 引语贵在立场/情怀/身份 | 引语承担情感/意义/自评,信息一律转述 |
| A20 | 纠偏文把反方写成稻草人 | 反方没实据,纠偏显得霸道 | 反方给"正常误解"式实据(man-eater 迷思有具体数据) |

## 诚实边界

1. **来源局限**:方法归纳自 Reading Explorer 1 与 2 两册(初中至初中高阶、共 48 篇);更高阶/学术文体另有写法
2. **分类非穷尽**:8 模块是"读出来的逻辑"而非唯一真理;杂交写法很多,模块是脚手架不是牢笼
3. **无法保证命题合规**:词汇覆盖率/超纲词/句长需用 vocab-checker、zhongkao-mcp 实测
4. **原创性**:模仿手法不等于复制内容;出稿需基于你提供的素材,不凭空编造事实与引语
5. **引语纪律**:无法查到出处的引语宁可不用(遵循女娲反模式:不编造"他没说过的话")

**调研时间**:2026年7月31日
**调研来源**:Reading Explorer 1 全册 24 篇 + Reading Explorer 2 全册 24 篇原文(MinerU 解析)+ 逐篇六维分析 + 8 模块库,详见 `references/research/`
