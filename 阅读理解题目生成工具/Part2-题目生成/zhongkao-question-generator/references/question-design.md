# 选择题设计规范

## 默认五题蓝图

| 位置 | 功能 | 常用考查 | 标准档 | 拓展档 | 段落落点 |
|---|---|---|---|---|---|
| 1 | 写作手法或细节 | 开篇引入方式(30%) 或 首段细节理解(70%)（提问/场景/故事/举例/数字/对比 / 时间/原因/方式/特征） | 首段首句或首段整体 | 可结合首段末句铺垫 | 固定第 1 段 |
| 2 | 词义或细节 | 词义猜测（定义/对比/因果/构词，70%）或细节理解（时间/原因/方式/特征，30%） | 同段或相邻句 | 可跨句或比较两处 | 前中部段落 |
| 3 | 推理判断 | 隐含信息、人物动机、后续发展、隐含因果、段落主旨（段落主旨题按 M-03 标 **MAIN IDEA**，不标 INFERENCE） | 同段或相邻句 | 可跨段 | 中间段落 |
| 4 | 排序或推断 | 事件/故事/时代顺序(80%) 或 推断(20%，复用 Q3 推理池) | 每个事件有明确时间标记或序列词 | 可跨段时间线 | 排序→全文（跨段素材）；推断→中间/跨段 |
| 5 | 主旨 | 最佳标题、全文主旨、写作目的；**文章已有标题时不出最佳标题（M-01），改出推断题（I 类）** | 覆盖全文主线 | 同时覆盖主张和限制 | 全文（覆盖主线） |

蓝图题位固定：Q1 写作手法(30%) 或 细节理解(70%)，Q2 词义猜测(70%) 或 细节理解(30%)，Q3 推理判断（含段落主旨；段落主旨题按 M-03 标 **MAIN IDEA**），Q4 排序(80%) 或 推断(20%，推断:排序 = 1:4，复用 Q3 推理池)，Q5 主旨大意（文章已有标题时改出推断题）。五题必须覆盖五种不同能力，不能都写成单句定位题。拓展档至少一道题需要跨段、作者观点或论证关系。

**段落落点规则（证据随行文顺序分布）：** 除 Q4 排序、Q5 主旨两道全篇题外，其余题目的证据段落按文章从前到后的顺序分布，避免题目扎堆在同一段或证据位置前后乱序。Q1 写作手法固定首段（开篇引入本就定位首段）；Q2 取前中部段落，Q3 取中间段落。文章正好 5 段时 Q1→第 1 段、Q2→第 2 段、Q3→第 3 段；多于 5 段时 Q2/Q3 落在前中/中间段落，使题目覆盖头部、中部、尾部三段式分布；少于 5 段时允许就近跨段，整体仍从前往后。排序、主旨不绑单段，分别依赖全文时间线和全文主线；Q4 抽中推断时按推断题落点（中间/跨段）。

**题型选择优先级：** 先判断文本的真实特征，再决定第 1 题考写作手法还是首段细节（蓝图按 30%/70% 加权抽取）、第 2 题考词义还是细节（蓝图按 70%/30% 加权抽取）。如果文本有明显值得推断的词义线索则考词义猜测（V 类），否则考细节理解（D 类）。Q1 抽中写作手法时必须能指认首段实际手法，抽中细节时证据须落在首段；Q4 抽中排序时原文必须有明确时间标记/序列词，否则改为推理或主旨（不强行套用不匹配的题型）；Q4 抽中推断时按 I 类规范出题（见"推理判断题（I 类）"）。Q2 词义/细节的可考点必须落在前中部段落，Q3 推理的可考点必须落在中间段落，若某个题位的可考点不在其应处段落，就近调整题位间分布而非破坏行文顺序。

## 常用题型

| 题型 | 正确项方法 | 合理干扰项 | 风险 |
|---|---|---|---|
| 写作手法 | 定位首段首句实际开篇手法，正确项 `By + V-ing` | 换手法（文中未用）、错位（别处手法安到开头）、未提及 | 首段无明确手法时不出 |
| 细节理解 | 对原文做自然同义转述 | 同段其他事实、对象错配、漏限定 | 不超过两题；避免原句照抄 |
| 信息整合 | 提取两处信息的共同属性或关系 | 只适合其中一处、拼接错误 | 不能只数关键词 |
| 词义猜测 | 语境义和词性均匹配 | 常见词典义但不合语境、词性不平行 | 正文必须提供可用线索 |
| 指代判断 | 语法和语义同时匹配 | 最近名词但逻辑不匹配、范围过大或过小 | 不要消除全部可考指代 |
| 排序 | 按原文时间标记/序列词排，选项为 ①~④ 序列 | 交换相邻、头尾颠倒、跨时代错位 | 原文必须有明确时间标记，否则不出 |
| 段落作用 | 指出例证、数据或转折支持的具体观点 | 只复述内容、泛称”吸引读者” | 先确认段落确有功能 |
| 推断 | 由两处证据逐步推出 | 扩大范围、倒置因果、加入常识 | 正确项不能超出证据 |
| 主旨/标题 | 同时体现对象和核心变化或观点 | 过宽、过窄、只覆盖一段 | 标题不只追求吸引力 |
| 作者观点 | 多个观点句和结论共同支持 | 常识正确但非作者观点、语气绝对 | 标准档慎用，拓展档推荐 |
| 结构 | 段落功能与结构符号一一对应 | 只按段数猜、主题句标错 | 结构不清时不出 |

### 写作手法题（WT 类）

| 编号 | 考点 | 命题模板 | 硬约束 |
|------|------|---------|--------|
| WT-01 | 提问引入 | How does the writer begin/lead in the topic? | 首段以问句引题；正确项 By asking questions |
| WT-02 | 场景/画面描述 | How does the writer begin the article to attract the readers? | 首段以 'Imagine...' 等描述画面；正确项 By describing a possible future situation |
| WT-03 | 讲故事引入 | How does the writer begin the article? | 首段讲一个小故事/案例；正确项 By telling a story |
| WT-04 | 举例引入 | How does the writer lead in the topic? | 首段给出具体例子；正确项 By giving an example |
| WT-05 | 列数字引入 | How does the writer begin the article? | 首段列出数据/统计；正确项 By listing numbers |
| WT-06 | 对比引入 | How does the writer lead in the topic? | 首段对照两个事物；正确项 By comparing two different ideas |

### 排序题（O 类）

| 编号 | 考点 | 命题模板 | 硬约束 |
|------|------|---------|--------|
| O-01 | 记叙文事件排序 | Put the events about X into the correct order. | 每事件有明确时间标记/序列词；事件标号 ①~④，选项为 ①~④ 序列（如 ②③①④，通常 3 个） |
| O-02 | 故事发展顺序 | Which of the following shows the correct order of what happened in the story? | 叙事时间线（开头→过程→结果）；事件标号 ①~④，选项为 ①~④ 序列 |
| O-03 | 说明文时代顺序 | What is the correct time order of the following events? | 朝代/时代标记（Tang Dynasty→Song Dynasty→nowadays）；事件标号 ①~④，选项为 ①~④ 序列 |

### 细节理解题（D 类）

| 编号 | 考点 | 命题模板 | 硬约束 |
|------|------|---------|--------|
| D-01 | 时间/地点/人物/数字 | （谁）在（何地/何时）（做了什么）？ | 答案在原文 ≤ 1 句范围内精确定位 |
| D-02 | 原因/结果 | Why...? / What causes...? | 原文需有 because / so / since / therefore 等显性因果标记，或 ≤ 2 句内可推断 |
| D-03 | 方式/手段 | How...? | 原文需有 by / through / with / using 等显性方式标记 |
| D-05 | 特征对比/属性 | Which of the following is true about...? | 答案与原文同义替换，核心语义不变 |
| D-06 | 信息匹配/排除 | Which is (NOT) mentioned? | 3 项在原文有依据，1 项无依据 |

> 注：原 D-04 事件排序已升级为独立 O 类排序题（固定 Q4），见下。事件排序题不归 D 类。

### 词义猜测题（V 类）

取材规则：目标词优先选**长难词**（70%），从文章**未加中文注释**的那部分生词中选取；已注释词不重复作考点。其余 30% 选**不太好理解的短语**。猜词题不与 Part 1 的中文注释重叠。

| 编号 | 考点 | 命题模板 | 硬约束 |
|------|------|---------|--------|
| V-01 | 定义/解释线索 | The word “X” means ______? | 原文 ≤ 2 句内有 means / refers to / that is / in other words 或同位语/定语从句解释 |
| V-02 | 对比/转折线索 | “X” probably means ______? | 原文含 but / however / while / instead of / unlike 标记 |
| V-03 | 因果关系线索 | “X” probably means ______? | 原文含 because / so / lead to / result in 因果链 |
| V-04 | 构词法线索 | “X” means ______? | 超纲词根 + 课标词缀 |

> **猜词题（V 类）题干格式**：统一以空线 `______` + 问号结尾（如 `The word "spray" in paragraph 3 probably means ______?`），不得以 `...` 结尾。validator 对此有咨询性检查。

### 推理判断题（I 类）

| 编号 | 考点 | 命题模板 | 硬约束 |
|------|------|---------|--------|
| I-01 | 隐含信息 | What can we infer / learn from...? | 正确答案不可为原文直接陈述；一步推理；默认针对全文（90%），段内推断仅占 10%（题干须写明段位） |
| I-02 | 人物心理/动机 | Why did the character...? / How did...feel? | 原文有行为描述 → 推断心理状态 |
| I-03 | 人物关系/身份 | Who is probably the writer? / Relationship? | 原文有称谓、说话方式等身份提示 |
| I-04 | 后续发展 | What will probably happen next? | 原文末段有伏笔/暗示 |
| I-05 | 写作目的/读者 | Who is it written for? / Purpose? | 依据语言难度、内容深度推断 |
| I-06 | 隐含因果 | What led to...? | 需综合多处细节推断 |
| I-07 | 信息合理性 | Which statement is probably true? | 3 个干扰项含事实/逻辑错误 |

### 主旨大意题（M 类）

| 编号 | 考点 | 命题模板 | 硬约束 |
|------|------|---------|--------|
| M-01 | 最佳标题 | What is the best title? | 覆盖全文核心，范围不过宽/过窄 |
| M-02 | 全文主旨 | The passage is mainly about... | 概括 ≥ 3 个段落核心信息 |
| M-03 | 段落大意 | What is paragraph X mainly about? | 对应主题句或核心事件 |
| M-04 | 写作目的 | What is the writer's purpose? | 限于 to inform/describe/persuade/entertain/warn/advise |
| M-05 | 文章来源 | Where is it probably from? | 匹配体裁特征 |

**标题干扰项错误类型：** 范围过宽 / 范围过窄 / 偏离主题 / 无中生有

### 观点态度题（P 类）

| 编号 | 考点 | 命题模板 | 硬约束 |
|------|------|---------|--------|
| P-01 | 作者态度 | What is the writer's attitude? | 原文 ≥ 2 处态度/情感/评价词 |
| P-02 | 作者观点 | What does the writer think of...? | 显性观点标记或 ≥ 2 处隐含评价 |
| P-03 | 人物观点区分 | 题干明确指向具体人物 | A 认为 X，B 认为 Y |
| P-04 | 情感变化 | How do the feelings change? | 原文有情感变化轨迹 |

**态度词汇库（限用课标词）：**
- 正面：positive, supportive, hopeful, proud, thankful, admiring, encouraging, satisfied, interested, excited, moving, inspiring
- 负面：negative, critical, doubtful, worried, disappointed, regretful, angry, sad, upset, helpless
- 中性：neutral, objective, factual, uncertain, questioning, serious
- **禁止：** sarcastic, indifferent, ambivalent, nostalgic, cynical, ironic, detached, dismissive, condescending, sentimental, skeptical

### 篇章结构题（S 类）

| 编号 | 考点 | 命题模板 | 硬约束 |
|------|------|---------|--------|
| S-01 | 指代关系 | What does “it / this / they / that” refer to? | ≤ 2 句范围内指代明确唯一 |
| S-02 | 衔接词 | What word can be put in the blank? | 考查 but / however / therefore / because / for example / besides / instead / first / then / finally |
| S-03 | 句子复位 | Where does the sentence best fit? | 复位后语义和指代连贯 |
| S-04 | 段落功能 | What is the function of paragraph X? | 限于 introduce / example / contrast / conclusion / background |
| S-05 | 信息组织方式 | How does the writer organize the text? | 限于 time order / problem-solution / cause-effect / comparison-contrast |

## 每题生成顺序

1. 写能力指标。
2. 标证据句编号和最远证据跨度。
3. 写 1—3 步推理链。
4. 写正确项，进行自然同义转述。
5. 设计与正确项同词性、同句式、相近长度和同抽象层级的干扰项。
6. 逐项写错误点。
7. 反向检查是否存在第二个可答项。

## 干扰项允许的错误机制

### 允许的干扰机制（8 种）

| 错因 | 定义 | 适用占比 |
|------|------|---------|
| 对象错配 | 信息匹配错误对象（张冠李戴） | 30% – 40% |
| 条件或限定缺失 | 省略了原文中的时间/地点/程度等限定条件 | 10% – 20% |
| 范围扩大或缩小 | 将部分说成全部、将全部说成部分 | 15% – 25% |
| 因果方向倒置 | 将原因说成结果、结果说成原因 | 5% – 15% |
| 时间顺序颠倒 | 事件发生先后顺序颠倒 | 5% – 10% |
| 局部真实但答非所问 | 选项内容在文中真实存在，但不回应题干问题 | 10% – 20% |
| 主题相关但不是本文重点 | 选项与文章主题一致，但非该题对应段落的核心信息 | 5% – 15% |
| 确定性膨胀 | 把可能写成确定、把一项研究写成多项共识 | 5% – 10% |

### 禁止使用的干扰手法

- ❌ 利用 `all / never / only` 等显眼绝对词泄露答案
- ❌ 语法错误（选项存在时态/主谓不一致等）
- ❌ 明显不平行的选项（长度/结构/抽象层级差异过大）
- ❌ 一个异常长或异常具体的正确项（泄露答案位置）
- ❌ 依赖文外常识争议（学生需课外知识才能排除）
- ❌ 与主题完全无关的荒谬项（学生无需读文即可排除）
- ❌ 部分正确的模糊地带（干扰项与正确项有重叠，造成双答案风险）

## 3 选项与 4 选项

- `option_count=3` 时，每题恰好 A—C。
- `option_count=4` 时，每题恰好 A—D。
- 选项数量变化不改变题目能力目标。
- 不为了凑第四项写低质量、明显错误的选项；如果用户允许，3 个高质量选项优于 4 个弱选项。

## 解析合同

每题都输出：

- 考查类型
- 对应课标能力
- 正确答案
- 证据原句或句号
- 推理步骤
- 每个干扰项的具体错误
- 难度：低 / 中 / 高，并说明来自词汇、跨度、关系还是抽象层级

## 证据账本与出题的关系

文章写作阶段建立的证据账本（事实 / 研究结果 / 专家观点 / 作者判断）直接服务于出题：

| 账本类型 | 适合考查的题型 | 设计要点 |
|---------|--------------|---------|
| 事实 | D 类细节题、V 类词义猜测 | 跨句整合替代单句照抄 |
| 研究结果 | I 类推断、V 类词义猜测 | 注意保留研究数量限定（a study ≠ studies） |
| 专家观点 | P 类观点态度、M 类主旨 | 区分直接引语和间接引语，不得混淆归属 |
| 作者判断 | P 类观点态度、I 类推断 | 语气强度不能因改写而改变（may ≠ will） |

## 单题质量检查

每题完成后逐项检查：

- [ ] 考点编号已标注（WT / D / V / I / O / M / P / S / R）
- [ ] 认知层次与题型匹配
- [ ] 题干定位明确
- [ ] 选项形式一致，长度均衡（最长 ≤ 最短 × 2）
- [ ] 干扰项有错因类型标注（归属 8 种允许机制之一）
- [ ] 答案不依赖超纲词
- [ ] 正确答案在原文唯一确定（无第二个可答项）
- [ ] 选项无 `all / never / always / only / none / every` 等显眼绝对词泄露答案
- [ ] 干扰项不是完全荒谬项（不读文也能排除的选项）

|--------|------|---------|

| 选项长度均衡 | 最长选项 ≤ 最短 × 2（词数）且 ≤ 30 字符差 | 通过/不通过 |
| 绝对词泄露 | `all / never / always / only / none / every / no one` 出现在选项中 | 标记预警 |

## 题组整体检查

每篇题组完成后逐项检查：

- [ ] 无前后题暗示（前题信息不能泄露后题答案）
- [ ] 难度排列递增（易→中→难）
- [ ] 选项分布均衡（A/B/C/D 频次差 ≤ 2）

## 特殊题型设计规则

### 信息匹配题（北京卷题型）

| 参数 | 标准 |
|------|------|
| 材料形式 | 4–5 个短文介绍（地点/活动/人物）+ 3 位"用户"需求描述 |
| 匹配逻辑 | 每位用户的需求与 1 个介绍匹配 |
| 答案形式 | 填入对应字母（A–D），1 项多余 |
| 选项词数 | 每段介绍 40–80 词 |
| 难度定位 | 低难度（题组第一题） |

### 7 选 5 句子复位题

| 参数 | 标准 |
|------|------|
| 语篇词数 | 200 – 300 词 |
| 语篇类型 | 记叙文或说明文为主 |
| 空数 | 5 个 |
| 选项数 | 6 个（含 1 个多余干扰项） |
| 选项类型 | 完整句（15–30 词）、过渡语 |
| 考查能力 | 段间逻辑连贯（因果/转折/递进）、指代衔接、语篇线索词识别 |
| 干扰项设计 | 语义相关但逻辑位置不符，或涉及"主题相关但不连贯" |

### 阅读表达（短答题）

| 参数 | 7 年级 | 8 年级 | 9 年级 |
|------|--------|--------|--------|
| 题量 | 0 – 3 题 | 0 – 5 题 | 0 – 5 题 |
| 题型类型 | 封闭式信息提取 | 封闭 + 半开放 | 封闭 + 半开放 + 开放 |
| 评分维度 | 内容相关 40% + 逻辑合理 30% + 语言准确 30% |

封闭题可摘抄原文关键词句；开放题需给出评分参考。

## 题干与选项规范

### 题干规范

| 规则 | 标准 |
|------|------|
| 题干长度 | ≤ 20 词（不含引文） |
| 语言难度 | 低于阅读文本一个级别 |
| 段落指向 | 必须明确（According to paragraph X / In paragraph X） |
| 否定式题干 | ≤ 2 题 / 题组 |
| 否定词标注 | NOT / EXCEPT 必须全大写或加粗 |
| 题干禁止 | "According to the passage" 范围过大——全文定位题除外 |

### 选项规范

| 规则 | 标准 |
|------|------|
| 数量 | 4 个（多数省份）/ 3 个（山西、江西、广西等） |
| 长度均衡 | 最长选项 ≤ 最短 × 2（词数） |
| 结构一致 | 同为名词短语 / 动词短语 / 从句 / 完整句 |
| 词汇控制 | 100% 课标词 |
| 干扰项来源 | 必须基于文中词汇或概念 |
| 重复词控制 | 共享词语写在题干中 |

### 正确答案分布

| 规则 | 标准 |
|------|------|
| A / B / C / D（或 A / B / C）频次差 | ≤ 2（20 题总量） |
| 连续同一选项 | 禁止 ≥ 3 次 |
| 首题答案 | 避免出现在最后位置（降低入口焦虑） |
