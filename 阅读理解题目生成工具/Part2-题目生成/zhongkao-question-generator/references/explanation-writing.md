# 答案解析撰写方法（真题对齐 · 2026 精品解析）

> 语料基准：2026 年 14 省市中考英语「精品解析（解析版）」的阅读理解部分。
> 全国解析高度同构：每篇短文 = 一行【答案】→【解析】→【导语】→ 逐题【N题详解】。
> 本文件定义 Part2 解析正文的撰写骨架，供导出 Word 的 `explanations` 参数使用：第 1 条为导语（不加编号、独立成段），其余逐题详解与题目一一对应（不带数字标号，导出器自动编号）。

---

## 一、整体结构

一组题目导出时，解析正文按以下结构组织：

1. **导语（每组/每篇一条）**：一句话压缩全文——体裁判定 + 内容概括（含结构顺序或主旨升华）。
2. **逐题详解（每题一条）**：`定位短语 + 逐字引原文 + 一句话下结论`（引证两段式）。

骨架模板：

```
【导语】本文（是/主要介绍/讲述了）+ 体裁词 + 内容概要（含对象/经过/结果/建议/主题）。

【1题】第X段（提到/指出/明确说明）"原文引句"，可知/说明/点明…（结论）。
【2题】…（每题一条，与题目一一对应）
```

> 注意：Part2 的 `explanations` 只传正文内容（导语 + 逐题详解），**不带数字标号**（导出器自动编号）；**导语必须作为第 1 条**（导出器识别 `len == 题目数 + 1` 后自动独立成段、不加编号、后接空行），其余逐题详解从 `1.` 开始编号。「正确答案」直接作为每题详解的结论句，无需单独写"答案为 X"行。

---

## 二、导语写法（三段式）

| 要素 | 写法 |
|------|------|
| 体裁判定 | 显式点出：说明文 / 记叙文 / 议论文 / 应用文 / 新闻报道 / 诗歌 |
| 内容概括 | 说明文按「对象 + 结构要点」；叙事文按「起因—转折—结局—启示」复述 |
| 主旨升华（可选） | 叙事/议论类可带升华句，如「告诉我们要保持求知欲」「传递了勇敢面对挑战的正能量」 |

真题示例：
- 说明文：「本文是一篇说明文，按时间顺序介绍了中国邮政及快递服务从古代到现代的发展历程及未来展望。」
- 记叙文：「本文讲述爱提问的女孩 Ananya 在老师鼓励下坚守好奇心、自主探究，最终学有所成，告诉我们要保持求知欲、敢于发问。」

## 三、每题详解（引证两段式）

骨架：`定位短语 + "逐字原文引句" + 结论动词 + 结论`

### 结论动词层级（每句只落一个结论）

| 层级 | 用词 | 适用 |
|------|------|------|
| 直接说明 | 说明 / 点明 / 指出 / 提到 / 明确说明 | 原文显性句、细节定位 |
| 综合推断 | 可知 / 可见 / 因此 / 由此可推断 / 推测 / 暗示 | 多句综合、推理题 |
| 来源推测 | 最可能出自 / 可能属于 / 属于…范畴 | 出处/文体判断、不引文 |

### 证据定位分级（由粗到细）

段级（最常用：第X段）→ 句级（第X段第X句 / 末句）→ 小标题级（"The Chinese Sturgeon"部分）→ 全文/尾句级（通读全文 / 最后一句）→ 图表/非文本级（图片 / 表格 / 作者署名 / 排版）。

---

## 四、干扰项处理（少而准）

- **多数题只讲正确项**：证据引完即止（`第X段"…"，可知…`），不逐项展开错误选项，靠引证正确项间接排除。
- **易混/高区分度题才显式排除**：词义近义、细节对错、主旨偏离、组合判断类，用**可验证否定**表述：
  - `文中无提及 / 未提及 / 非主旨 / 只有前者 / 只有后者 / 不是…的原因 / 信息不匹配`
  - 示例：「A 项文中无提及，C 项只有后者符合，只有 B 项符合二者的共同点。」
- **七选五/还原句**：以「前文…后文…」定位，用 `引出 / 衔接 / 呼应 / 承上启下 / 补充 / 符合语境` 说明选项与上下文的关系；多余选项不讨论。

## 五、分题型解析方法（抽到哪类用哪类）

| 题型 | 解析骨架 | 详略 |
|------|---------|------|
| 细节理解 D | `第X段"引句"，可知/说明…` | 最短：1 引 1 结 |
| 词义猜测 V | 引划线词所在句/前后句 → 说明语境线索（定义/对比/因果）→ `可知该词意为…，与选项X（近义）对应` | 中等 |
| 指代 S-01 | 引含指代词的原文句 → `这里的X指代前文…` | 中等 |
| 段落主旨 M-03 | 引主题句/核心事件 → 概括该段 | 中等 |
| 全文主旨 M-02 | 多段引文综合 → `通读全文可知，…因此主旨是…` | 中等偏长 |
| 最佳标题 M-01 | 多段引文锁定核心 → `X选项"…"最能概括文章主题` | 较长 |
| 写作手法 WT | 引首段（或相关段）实际手法 → 与选项 `By + V-ing` 对应 | 中等 |
| 写作目的 M-04 | `通读全文可知，…因此写作目的是…` | 中等 |
| 出处 M-05 | 按内容特征/体裁判断，不引文：`这类内容最可能出现在…` | 短 |
| 推断 I-01~07 | 引证 + 推断链：`第X段"…"可知/由此可推断…，因此…` | 较长 |
| 人物特征评价 I-09 | 由全文行为/语言推断 → 与选项形容词对照 | 中等偏长 |
| 读后启示 I-10 | 由故事主旨升华：`本文以…为例，告诉/说明…，X选项契合…` | 中等偏长 |
| 段落功能/例证 S-04 | 指出该例证/数据/转折支持的具体观点 | 中等 |
| 排序 O | `由"引文"可知，起初…；然后…；最后…。正确顺序为：…`（逐环节推进，回扣选项序列） | 最长 |
| 表格综合 | 逐项核对排除：`周一…，周二…，因此…` | 较长 |
| 七选五 | `前文…后文…，选项X"…"衔接上下文，符合语境` | 较长 |

## 六、详略随题型分化

- **细节题**：1 句引文 + 1 句结论，点到即止。
- **推理题**：比细节题多「概括 + 推断链 + 与选项对照」两环。
- **排序题**：按"由'引文'可知 + 起初/然后/最后"逐环节推进，回扣选项序列字母。
- **主旨/标题题**：多段引文锁定核心，最后回扣正确选项原文。
- **表格/综合题**：逐项核对排除。
- **七选五**：前后文衔接逻辑。

---

## 七、语言规范

- 解析正文**全中文叙述**，原文引证保留英文，引文用中文引号包裹。
- 专名/生词随文注中文（如「细菌（bacterium）」）。
- 术语固定：定位 / 细节 / 主旨 / 推断 / 同义替换 / 衔接 / 符合语境 / 指代 / 点明主旨 / 划线词。
- 解析文本不带数字标号（`explanations` 每条只写内容本身，导出器自动编号）。
- 答案字母大写、无句号。

---

## 八、与 Part2 现有约定的关系

Part2 解析须同时满足项目约定：**正确答案、原文证据、干扰项错误点（中英文均可）**。真题对齐后对应关系：

| 现有约定 | 真题对齐写法 |
|---------|------------|
| 正确答案 | 每题详解的结论句（`可知/因此…`） |
| 原文证据 | 定位短语 + 逐字引原文（证据定位分级） |
| 干扰项错误点 | 按"少而准"原则：多数题从简（只讲正确项即间接排除）；易混题显式点出可验证否定 |
