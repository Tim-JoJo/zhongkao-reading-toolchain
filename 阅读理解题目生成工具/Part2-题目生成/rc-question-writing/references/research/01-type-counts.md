重新按 4 类归类(PURPOSE、GIST 并入 MAIN IDEA;代词指代并入 VOCABULARY)。

## 各类题出现过的单元(节选,来自各 docx 的 unit 标注)

**DETAIL**(88):第三版 1A~12B 全覆盖 + 第二版各单元。基座题型,每课 1-3 题。

**MAIN IDEA**(66):吸收原 GIST(another title / mainly about)与 PURPOSE(整篇目的 / 为什么提 X),另含段落主旨、段落 heading。是"全篇/段落级理解"的汇聚类。

**VOCABULARY**(44):词义猜测 25 + 代词指代 19(it/they/this/those/their refer to)。指代题统一归入本类。

**INFERENCE**(35):仅保留"需推导一步"的推理题——作者/人物立场(Which statement would X agree with)、意图动机(Why did X)、引语/隐喻解读(What does X mean by)、概念迁移/举例辨识(Which is an example of)、图表理解、可确定性判断(which can we definitely say)。已移出代词指代(→VOCABULARY)与"为什么提 X"(→MAIN IDEA)。

## 分布规律(出题参考)

1. **DETAIL 占比最大(37.8%)**:基座题型,保证基础分。
2. **MAIN IDEA 第二大类(28.3%)**:全篇/段落级理解汇总,含标题、主旨、目的。
3. **VOCABULARY 第三(18.9%)**:词义 + 指代,分散在各课。
4. **INFERENCE 最少(15.0%)**:区分度所在,压缩为纯推理。
5. **指代不再是独立考点**:it/they/this 的指代判断归入 VOCABULARY(词的单位辨析)。
6. **"为什么提 X"不再是独立考点**:提及/举例意图归入 MAIN IDEA(全篇/段落功能)。

## 教材常见配置(5 题/组)

- 2 DETAIL + 1 MAIN IDEA + 1 VOCABULARY + 1 INFERENCE 是常见组合。
- 第 5 题轮换:VOCABULARY / INFERENCE / MAIN IDEA 按课文特点出现。
- 难度阶梯:先细节后推理,INFERENCE 常压轴。
