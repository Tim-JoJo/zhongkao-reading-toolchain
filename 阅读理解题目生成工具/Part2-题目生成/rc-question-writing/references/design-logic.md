# 出题逻辑 · 类型分界与通用手法

> 核心信仰:**出题不是选对的那个,是造出三个看起来都对、但只有一个对的。**
> 正确项要"唯一",干扰项要"像真的但可排除"。

---

## 〇、出题全局规则(先读)

1. **选项数量**:默认 4 选项(a/b/c/d)。只有用户明确要求 3 选项时才用 3(教材多数题 3 选项,但出题规范按 4 选项做)。
2. **答案分布**:5 题卷尽量让 A/B/C/D 分散出现,不要同一字母连选 3 次以上。
3. **选项长度**:4 个选项长度/信息量尽量均衡,防止"最长的一定对"这类规律泄题。正确项不要显著比干扰项长。
4. **单段短文适配**:素材只有一段时,指代题(原 REFERENCE,已并入 VOCABULARY,考段落内行号)、段落级主旨题("What is paragraph C mainly about?")不可用。改用全文版:指代考"this sentence / in this reading",段落主旨改考全文 title/mainly about。
5. **交付格式**:每题按固定格式给出——
   ```
   Qn. [题干]
   A. ... B. ... C. ... D. ...
   答案:X · [题型]
   考点出处:[文章哪句]
   正确项依据:[为何对]
   干扰项排除:[逐项:哪个模具+错在哪]
   ```
   **轻量模式**(用户只要题目时):只交付 `Qn. [题干] / A-D / 答案:X·题型` 三行,省略考点出处与排除依据;用户要纯练习卷时连答案也省略。
6. **交互**:真人对话时,Step 1(定考点分布)可先给一行清单,快速模式不等确认继续;敏感/方向不确定时停下等确认。

## 一、类型分界表(最常搞混的题型)

| 分界 | 题型A | 题型B | 判定测试 |
|------|-------|-------|---------|
| **零推理 vs 一步推导** | DETAIL(原文直接可查) | INFERENCE(需推导一步) | 学生不看出题,只看原文能否直接答出?能→DETAIL |
| **整体 vs 局部** | MAIN IDEA(全篇/段落大意、目的) | DETAIL(局部事实) | 问"整篇/整段讲了什么、为什么写"→MAIN IDEA;问"某个具体事实"→DETAIL |
| **标题/大意 vs 主旨/目的**(MAIN IDEA 内部) | 内容问法(title/mostly about) | 功能问法(purpose/mention/heading) | 问"写了什么"→内容;问"为什么写/段落功能"→目的 |
| **词 vs 句** | VOCABULARY(这个词/代词什么意思) | INFERENCE(这句/这个隐喻在说什么) | 题干引号内是"一个词/代词"→VOCABULARY;是"一个句子/引语且考含义"→INFERENCE |
| **词义 vs 指代**(VOCABULARY 内部) | 考语境义(means) | 考指代对象(refers to) | 题干问"X means"→词义;问"X refers to"→指代 |

### 最易误判的一对:DETAIL vs INFERENCE
- 分界测试:**正确项在原文能找到原句/直接转述 → DETAIL;原文没有这句话、需要推理 → INFERENCE。**
- 反面示例:第三版 3B-Q11"Schlaug 怎么帮中风病人说话"→原文直接说"by getting them to sing"(DETAIL)。若问"为什么唱歌能帮说话"→需推导(INFERENCE)。
- NOT 反向题(DETAIL)与"可确定性判断"(INFERENCE):DETAIL-NOT 的正确项是"原文明确没有";INFERENCE-definitely 的正确项是"原文明确有的事实",干扰项才是推测。看正确项朝向。

## 二、通用干扰项手法(所有题型共用)

出干扰项时有 5 个"模具",每个干扰项至少套一个,且必须能指认排除依据:

| # | 手法 | 定义 | 示例 |
|---|------|------|------|
| 1 | **字面/碎片化** | 截取原文某词,偷换语义或过度发挥 | 把比喻当字面、把部分当全部、把举例当规则 |
| 2 | **极端化** | 推向"绝对肯定/全盘否定",超出文本能支持的范围 | 正确项带 probably/may,干扰项带 definitely/all/never |
| 3 | **张冠李戴** | 把 A 的事实/属性安到 B 头上 | 把此人做的事说成彼人做的 |
| 4 | **未提及但合理** | 听着合理,但文章没提(NOT 题核心) | 常识上对、文本里没有 |
| 5 | **部分正确** | 开头对结尾错,或主谓搭错 | 主语对、谓语错;前半真、后半假 |

**干扰项质量自检**:每个干扰项都必须能回答"它错在哪"——套不出上述任一模具的干扰项,重做。
**正确项唯一性自检**:若两个选项都对(或都对/都不对),出题事故,回炉。

## 三、正确项设计原则(通用)

| 原则 | 说明 | 违反后果 |
|------|------|---------|
| **源自原文** | 正确项必须有原文依据(可查/可推导) | 凭空正确项=瞎猜 |
| **唯一指向** | 题干锁定唯一考点,正确项唯一 | 多解=事故 |
| **忠实但加工** | DETAIL 忠实转述;其他题型换表达、概括、推导 | 抄原句=DETAIL 化,考不到理解 |
| **梯度词控制** | INFERENCE 正确项常用 probably/may/reasonable | 绝对化易误伤(除非可确定性判断题) |

## 四、反模式详解(10 条,审校时逐条过)

| # | 反模式 | 识别信号 | 正确做法 |
|---|--------|---------|---------|
| W1 | 正确项直接抄原文整句(DETAIL 除外) | 正确项与原文某句几乎逐词相同 | 换表达/概括/推导,考理解 |
| W2 | 干扰项无排除依据 | 说不出干扰项错在哪 | 每个干扰项套干扰项模具 |
| W3 | 题干含多余信息/暗示答案 | 题干能推出答案 | 题干只给解题所需信息 |
| W4 | INFERENCE 干扰项绝对化 | 干扰项带 all/never/must/definitely | 设计"看似合理但证据不足",不设计"一眼假" |
| W5 | VOCABULARY 考常见义 | 正确项是词典第一个义项 | 考本语境义 |
| W6 | 指代对象超出段落语境 | 指代对象不在本段 | 指代对象本段可定位 |
| W7 | 主旨类问法混淆 | 标题/大意、主旨/段落、目的/提及意图 混用 | 按 MAIN IDEA 内部三问法分:title=内容、main idea of paragraph=段落论点、purpose/mention=功能 |
| W8 | 句意题正确项几乎同词 | 正确项与原文同词 | 正确项换表达 |
| W9 | 一题多解 | 两个选项都对 | 锁定唯一考点 |
| W10 | 硬凑考点 | 考点与文章无关/太牵强 | 出不了就减题 |

## 五、整卷配置与分布规律(源自 233 题统计)

### 4 类题量(Reading Explorer 1 两册实测)
| 题型 | 数量 | 占比 |
|------|------|------|
| DETAIL | 88 | 37.8% |
| MAIN IDEA(含原 GIST/PURPOSE) | 66 | 28.3% |
| VOCABULARY(含代词指代) | 44 | 18.9% |
| INFERENCE | 35 | 15.0% |
| **合计** | **233** | **100%** |

### 分布规律
- **DETAIL 最大(37.8%)**:基座题型,保证基础分。
- **MAIN IDEA 第二(28.3%)**:全篇/段落级理解汇总(标题、主旨、目的、提及意图)。
- **VOCABULARY 第三(18.9%)**:词义 + 指代,分散各课。
- **INFERENCE 最少(15.0%)**:区分度所在,纯推理,常压轴。
- **指代不再是独立考点**:it/they/this 指代归入 VOCABULARY。
- **"为什么提 X"不再是独立考点**:提及/举例意图归入 MAIN IDEA。

### 教材题号分布(观察:INFERENCE 常压轴)
- INFERENCE 大量出现在每组第 4-5 题(课文后部考点):第三版 12A-Q5、12B-Q5、11A-Q5 等。
- DETAIL 多在前 3 题;MAIN IDEA 多在中间;INFERENCE 压尾——难度阶梯:先细节后推理。

### 新题型题位(中考英语作业题实测)
- **写作手法固定 Q1**(开头引入,首题入口题):3 篇真题全部在第 1 题。
- **排序固定 Q4**(事件/时代顺序,倒二有区分度):3 篇真题全部在第 4 题。
- 二者对应中考题组"1. 写作手法 2-3. 细节/推断 4. 排序 5. 主旨/标题"的常见题位。

## 六、出题工作流速查(场景A 用)

```
文章 → 定考点分布(5 题) → 逐题:
  1. 选子模式(question-type-library.md)
  2. 写题干(套模板,锁唯一考点)
  3. 写正确项(原文依据 + 加工)
  4. 写干扰项(5 模具各套一,能指认排除依据)
→ 自检:正确项唯一?干扰项都可排除?题型不混淆?
→ 交付:每题附考点出处 + 正确项依据 + 干扰项排除依据
```

### 新题型速查
- **写作手法**(Q1):读首段→判定手法(提问/场景/故事/举例/数字/对比)→正确项 `By + V-ing`→干扰项换手法/错位/未提及。
- **排序**(Q4):先确认原文有明确时间标记/序列词→列 4 事件(①/②/③/④ 标注,一行一个)→选项 ①~④ 序列(通常 3 项)→干扰项交换相邻/头尾颠倒/跨时代错位。
