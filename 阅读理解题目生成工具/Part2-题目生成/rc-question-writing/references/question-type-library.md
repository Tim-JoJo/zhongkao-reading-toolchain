# 4 大题型库 · 逐类出题规格

> 每类包含:定义 / 子模式(出题可选项) / 题干模板 / 教材真题例 / 正确项原则 / 干扰项手法。
> 题例均取自 Reading Explorer Level 1(第三版 + 第二版)Reading Comprehension,233 题按 4 类归类。
> **4 类命名**来自教材蓝色标签: DETAIL 细节理解 / INFERENCE 推理判断 / MAIN IDEA 主旨 / VOCABULARY 词义猜测。
> **合并说明**:PURPOSE、GIST 已并入 MAIN IDEA;代词指代已并入 VOCABULARY。

---

## 1. DETAIL — 细节理解(88 题,题量最大)

**定义**:答案在原文直接陈述、零推理。考的是"定位 + 辨认"能力,不是理解推导。

### 子模式
| 子模式 | 题干特征 | 教材题例 |
|--------|---------|---------|
| 正向事实 | Which sentence is/true...? | "Which sentence about dolphin language is true?"(第三版 1A) |
| **反向事实** | Which is NOT true / NOT mentioned? | "Which of these sentences is NOT true?"(第三版 1B) |
| 原因 | Why did / Why does...? | "Why do dolphins sometimes help fishermen?"(第三版 1A) |
| 过程步骤 | What is the first thing...? | "When a smokejumper reaches a fire site, what is the first thing he or she does?"(第三版 9B) |
| 数据/数量 | How many...? | "How many plastic bags are used in the United States every year?"(第三版 11B) |
| 人物-事实匹配 | What two groups did X study? | "What two groups did Nina Kraus study?"(第三版 3B) |
| 方法/行为 | How does X do Y? | "How does Gottfried Schlaug help stroke patients speak?"(第三版 3B) |
| **事实 vs 推测(第二版)** | Which statement is a fact and not speculation? | "Which statement is a fact and not speculation?"(第二版 6B) |
| **时间/顺序** | Shortly after X, what happened? | "Shortly after taking off from New Guinea, what happened?"(第三版 12B) |

### 题干模板
```
Which [sentence/statement] [is true / is NOT true / is NOT mentioned] about [X]?
Why did [X] [do Y]?
What [is the first thing / did X do] ...?
How does [X] [do Y]?
Which statement is a fact and not speculation?
```

### 正确项原则
- 严格原文可查:正确项是原文某句的**忠实转述**(换词不换义,如 synonyms)。
- 反向题(NOT true):正确项是**原文明确没有**或与原文矛盾的那句。

### 干扰项手法
1. **张冠李戴**:把 A 的事实安到 B 头上。
2. **部分正确 + 偷换**:开头对、结尾错,或主语对、谓语错。
3. **原文未提但看似合理**:NOT 题干扰项的核心——选项内容听着合理,但文章没提。
4. **动机错配**:把"真实动机"换成"道德动机"。

### 与 INFERENCE 分界(最关键)
- DETAIL:原文直接给答案,定位即得。
- INFERENCE:答案需**推导一步**,原文没有直接说。
- 分界测试:学生不看选项、只读原文能否直接答出?能 → DETAIL;不能 → INFERENCE。

## 2. MAIN IDEA — 主旨(66 题,第二大类,含原 GIST 全文主旨 + PURPOSE 写作目的)

**定义**:考全篇/段落"大概讲了什么 + 为什么写",区分主次与目的,不做细节推导。是原 GIST(标题/大意)、PURPOSE(目的/提及意图)、原 MAIN IDEA(段落主旨)三者的汇聚类。

### 子模式
| 子模式 | 题干特征 | 教材题例 |
|--------|---------|---------|
| **另起标题** | What could be another title? | "What could be another title for this reading?"(第三版 2A) |
| **最佳标题变体** | What would be the best alternative title? | "What would be the best alternative title for the passage?"(第二版 1B) |
| **全文主旨** | What is the reading mainly about? | "What is the reading mainly about?"(第三版 3A) |
| 故事梗概 | What is this story mainly about? | "What is this story mainly about?"(第三版 8B) |
| **问答题式概括(第二版)** | How does the passage answer "X"? | "How does the passage answer 'Was King Tut murdered?'"(第二版 3A) |
| 人物总评 | What is the best description of X? | "What is the best description of Ibn Battuta?"(第二版 8B) |
| 体裁判断 | The passage consists of... | "This passage generally consists of ______."(第三版 11B:suggestions) |
| **全文目的** | What is the main purpose of this reading? | "What is the main purpose of this reading?"(第三版 9A) |
| **动词辨析** | to describe vs to explain vs to compare | "The main purpose of this reading is to describe ______."(第三版 10B) |
| **段落主旨** | What is the main idea of paragraph X? | "What is the main idea of paragraph B?"(第三版 10A) |
| **段落大意** | What is paragraph X mainly about? | "What is paragraph C mainly about?"(第三版 10B) |
| 段落目的 | What is the purpose of paragraph X? | "What is the purpose of paragraph B?"(第二版 4A) |
| **段落标题(第二版)** | What would be the best heading for the last paragraph? | "What would be the best heading for the final paragraph?"(第二版 10A) |
| **段末总结(第二版)** | Which sentence best expresses the main idea of the final paragraph? | "Which sentence best expresses the main idea of the final paragraph?"(第二版 6A) |
| **结论归纳(第二版)** | Which statement best summarizes the conclusion X draws? | "Which statement best summarizes the conclusion Ariely draws in paragraph E?"(第二版 11B) |
| 结构功能 | Paragraphs C and D focus on... | "Paragraphs C and D focus on the advantages of ____ while exercising."(第三版 3A) |
| 排除式 | What does the reading NOT mention? | "What does the reading NOT mention?"(第三版 1A) |
| 比较归纳 | How are X and Y similar? | "How are volcano surfing and land diving similar?"(第三版 2B) |
| **提及意图(第二版)** | Why does the author mention X? | "Why does the author mention Al Sadu?"(第二版 4A) |
| **举例目的(第二版)** | The author uses the example of X to show that... | "The author uses the example of the bat and ball question to show that..."(第二版 11A) |
| **指称意图(第二版)** | The author refers to X to indicate that... | "The author refers to Ilannguaq Egede to indicate that..."(第二版 10B) |

### 题干模板
```
What could be another title for [this reading / paragraph X]?
What would be the best alternative title for the passage?
What is the reading mainly about?
What is paragraph X mainly about?
What is the main idea of paragraph X?
What is the [main] purpose of [this reading / paragraph X]?
The main purpose of this reading is to [describe/explain/compare/...] ______.
Why does the author mention [X]?
The author uses the example of [X] to show that ______.
The author refers to [X] to indicate that ______.
What would be the best heading for paragraph X?
```

### 正确项原则
- 标题/大意型:能概括**全篇或全段**整体,而非任何单点细节。标题覆盖主体内容,不夸大、不缩小。
- 目的型:正确项 = **功能动词 + 对象** 都准确。动词取决于文章主要动作:介绍新事物→describe;解释原因→explain;对照→compare;号召行动→encourage/persuade;呈现信息→give information about。
- **提及/举例/指称意图**:回答"为什么这里提到 X",X 在文中的作用是支撑作者某观点,不是 X 本身的内容。

### 干扰项手法
1. **过窄(细节冒充主题)**:只覆盖文章一部分(例:第三版 1B 干扰项"Octopus Numbers on the Rise"只是文末一句)。
2. **过宽/跑题**:太泛或偏离文章主体。
3. **以偏概全**:把文章中的某个例子当整体主题。
4. **动词错配**(目的题):对象对但动词错。
5. **意图错位**(提及/举例题):把"举例的目的"换成"X 本身的内容"。

### 分界(内部三大问法)
| 问法 | 考什么 | 提问关键词 |
|------|--------|---------|
| **标题/大意** | 写了什么(内容) | title / mainly about |
| **主旨/段落** | 论点/段落中心 | main idea of paragraph X / heading |
| **目的/意图** | 为什么写(功能) | purpose / Why does the author mention |

- 与 DETAIL 分界:MAIN IDEA 考"整体",DETAIL 考"局部事实";一篇文章可同时出 MAIN IDEA + DETAIL。

## 3. VOCABULARY — 词义猜测(44 题,第三大类,含代词指代)

**定义**:考单词/词组在**本语境中的实际含义**,或代词在文中的**指代对象**。都落在"词/短语单位"的理解上。

### 子模式
| 子模式 | 题干特征 | 教材题例 |
|--------|---------|---------|
| 单词词义 | What does X mean? | "In paragraph A, what does the word 'miniature' mean?"(第三版 6A:very small) |
| 词组词义 | What does "turned into" mean? | "What does 'turned into' mean?"(第三版 8B:changed to) |
| **条件句替换** | If X turned back, they ____ | "If Mallory and Irvine turned back, they ______ the mountain."(第三版 12A) |
| 同义近义 | most similar in meaning to | "Which of these words or phrases is most similar in meaning to 'ran out of'?"(第三版 12B) |
| **语义场猜词(第二版)** | X is closest in meaning to ___ | "In paragraph B, the word 'culprit' is closest in meaning to ___."(第二版 1A) |
| **词块/搭配(第二版)** | What does "goes both ways" mean? | "What does 'goes both ways' mean?"(第二版 2A) |
| **短语替换(第二版)** | What can "lets you go" be replaced with? | "What can the words 'lets you go' be replaced with?"(第二版 12A) |
| **代词指代(原 REFERENCE)** | What does [X] refer to? | "What does 'Many' refer to in paragraph C?"(第三版 5B) |
| **带行号定位** | ...in paragraph D, line 4? | "What does 'they' refer to in paragraph D, line 4?"(第三版 1B) |
| **引语内指代** | What does 'our' in the quote refer to? | "What does 'our' in Stephen Hawking's quote refer to?"(第三版 4A) |
| **名词短语指代** | What does the phrase 'the very thing' refer to? | "What does the phrase 'the very thing' refer to?"(第二版 1A) |
| **地点副词指代** | What does 'here' refer to? | "In paragraph E, what does 'here' refer to?"(第二版 4B) |

### 题干模板
```
In paragraph X, what does [the word / "phrase"] mean?
What does [X] refer to / mean in [context]?
If [X verbed], they ______.
Which of these words is most similar in meaning to "X" in paragraph Y?
[word] is closest in meaning to ______.
What does "[pronoun]" refer to in paragraph [Y][, line Z]?
```

### 正确项原则
- 词义:正确项 = 该词在**本句/本段语境义**,必须能用上下文证据支撑(同义复现、反义对照、下定义、举例、因果)。
- 指代:三条件齐判——①就近原则(指代对象通常在前文最近处)②单复数一致(they/them/those→复数;It→单数;Many→可数复数)③语义复现(指代对象与代词语义接得上)。

### 干扰项手法
1. **字面常见义(最典型)**:考"本语境义 vs 常见义"之差(例:average 选"typical",干扰项"smart";immediately 选"right away",干扰项"completely")。
2. **近义混扰**:与正确义有细微差别的近义词。
3. **完全不相干**:从词形或读音硬扯。
4. **同段其他名词**(指代题):也在附近出现,但单复数不符或语义接不上(例:"they"指 violinists,干扰项放 orchestra musicians)。
5. **范围过大/过小**(指代题):指向概念更大的词或更窄的词。

### 分界
- VOCABULARY 考"词/短语单位"(词义 or 指代);INFERENCE 考"句子/论证层推理"。
- 题干引号内是"一个词/代词"→ VOCABULARY;是"一个句子/引语且考其含义"→ INFERENCE 引语解读(注意:指代 it/they 本身在 VOCABULARY)。

## 4. INFERENCE — 推理判断(35 题,最少但区分度最高)

**定义**:答案从不在原文直接出现,需要**推导一步**。正确项与原文是"间接成立"关系。不含代词指代(→VOCABULARY)、不含"为什么提 X"(→MAIN IDEA),是纯推理。

### 子模式
| 子模式 | 题干特征 | 教材题例 |
|--------|---------|---------|
| **观点一致性** | Which statement would X probably agree with? | "Which statement would Anker probably agree with?"(第三版 12A) |
| 言语/行为意图 | Why does X say/do...? | "Why does X say '...'?"(第三版 7B) |
| 基于证据的推测 | probably / reasonable conclusion | "A reasonable conclusion from paragraphs B and C is that ______."(第三版 12A) |
| 作者暗示 | the author suggests... | "In paragraph C, the author suggests that some corals..."(第三版 1B) |
| 可确定性判断 | Which can we definitely say? | "Which of these can we definitely say about Jymmin machines?"(第三版 3A) |
| **概念迁移/应用** | 把概念套到新例子 | "Which of the following is a single-use item?"(第三版 11A) |
| **举例辨识(第二版)** | Which is an example of X concept? | "Which is an example of conformist bias?"(第二版 9A) |
| **图表理解(第二版)** | The infographic on page X shows... | "The infographic on page 15 shows ___."(第二版 1B) |
| 故事寓意 | 从故事提炼教训 | "What lesson or moral is taught in this story?"(第三版 8B) |
| 因果推断 | 由现象倒推原因 | "Why was Deinocheirus a mystery for so long?"(第三版 7B) |
| **引语/隐喻解读** | What does X mean by "..."? | "What does DiCaprio mean by 'the future of the planet is at stake'?"(第二版 9B) |
| 情境推断 | 由行为/状态推含义 | "In red light, an octopus probably appears ___."(第三版 1B) |

### 题干模板
```
Which statement would [person] probably agree with?
Which of these can we definitely say about X?
A reasonable conclusion from paragraphs X and Y is that ______.
In paragraph C, the author suggests that ______.
Which of the following is an example of [concept]?
The infographic on page X shows ______.
Why was X a mystery / Why does X say...?
What does [person] mean by "[quote]"? / What does "[metaphor]" mean?
```

### 正确项原则
- 一步推理:正确项 = 原文信息 + **一步合理推导**。推导步骤必须写得出(信息A + 信息B → 结论C)。
- 引语/隐喻解读:正确项 = 说话人**实际想表达的意思**,不是字面;结合立场判断。
- 可确定性判断:正确项反而是原文明确事实(干扰项才是推测)。

### 干扰项手法
1. **字面/碎片化**:截取原文某个词,语义被偷换或过度发挥(把比喻当字面、把部分当全部)。
2. **极端化**:把推断推向"绝对肯定"或"全盘否定"(正确项带 probably/may,干扰项带 definitely/all/never)。
3. **望文生义**(引语题):按字面/常见义理解隐喻。
4. **超出证据**:推得过头,原文证据撑不起。
5. **套用常识**:常识上合理但文章没提。

### 分界
- **与 DETAIL**:零推理 vs 一步推导(见 DETAIL 分界)。
- **与 MAIN IDEA**:INFERENCE 推出"某个具体判断",MAIN IDEA 概括"整体讲了什么/为什么写"。
- **与 VOCABULARY**:INFERENCE 考"句子/论证层",VOCABULARY 考"词/短语单位"(含指代)。

## 5. 写作手法 · 开篇引入(新增,固定 Q1 小题)

**定义**:考作者用什么手法引入话题/吸引读者。属篇章结构(S 类),与"为什么提 X"同族(都是写作手法考察)。基于 3 篇真实中考英语作业题归纳。

### 子模式
| 子模式 | 题干特征 | 正确项句式 | 判定依据 |
|--------|---------|-----------|---------|
| **提问引入** | How does the writer lead in the topic? | By asking questions | 首段以问句引题(Are you afraid...? But did you know...?) |
| **场景描述** | How does the writer begin the article to attract the readers? | By describing a possible future situation / a clear picture | 首段以 "IMAGINE THIS" / "Imagine this" 描述画面 |
| 讲故事 | 同上 | By telling a story | 首段讲一个小故事/案例 |
| 举例 | 同上 | By giving an example | 首段给出具体例子 |
| 列数字 | 同上 | By listing numbers | 首段列出数据/统计 |
| 对比 | 同上 | By comparing two different ideas | 首段对照两个事物 |

### 题干模板
```
How does the writer begin the article [to attract the readers]?
How does the writer lead in the topic?
```

### 正确项原则
- 正确项 = **By + 动名词** 平行结构,描述首段的实际开篇手法。
- 依据 = 定位**首段首句/首段整体**判断用的是什么手法。

### 干扰项手法
1. **换手法**:其他合理的开篇方式,但文中没用(例:文章用场景描述,干扰项写"By asking questions")。
2. **错位**:把文中**别处**的手法安到开头(例:文中第二段解释了科学背景,干扰项写"By explaining the scientific background")。
3. **未提及**:开篇方式文本里根本没出现。

### 分界
- 与 MAIN IDEA"为什么提 X":写作手法专考**开篇(第一段)用什么方式**,为什么提 X 考**文中任意处的提及目的**。
- 与 S-04 段落功能:写作手法 = 开头段落的功能(引入方式),是 S-04 的特化版。

## 6. 排序 · 事件/时代顺序(新增,固定 Q4 小题)

**定义**:考事件/步骤/时代的先后顺序。属信息组织(S-05)与局部信息整合(D-04)交叉。基于 3 篇真实中考英语作业题归纳。

### 子模式
| 子模式 | 题干特征 | 判定依据 |
|--------|---------|---------|
| **记叙文事件排序** | Put the events about X into the correct order | 每事件有明确时间标记/序列词(first→then→a year and a half later) |
| **故事发展顺序** | Which of the following shows the correct order of what happened in the story? | 叙事时间线(开头→过程→结果) |
| **说明文时代顺序** | What is the correct time order of the following events? | 朝代/时代标记(Tang Dynasty→Song Dynasty→nowadays) |

### 题干模板
```
Put the events about [X] into the correct order.
Which of the following shows the correct order of what happened in the story?
What is the correct time order of the following events?
```

### 选项设计(关键)
- 先给 **4 个事件 ①/②/③/④**(每事件一句话,一行一个)。
- 选项 = **①~④ 序列**(如 ②③①④)。
- 通常 **3 个选项**(中考试卷排序题惯例),也可 4 个。
- 每个事件必须是原文中**定位明确的一件事**(能指认到出处句)。

### 正确项原则
- 严格按原文**时间标记/序列词**排序,不是按内容逻辑猜。
- 说明文时代排序:按朝代/时期先后。

### 干扰项手法
1. **交换相邻**:只把相邻两个事件的顺序调换。
2. **头尾颠倒**:把最早/最晚事件位置对调。
3. **跨时代错位**:说明文里把不同时代的顺序弄乱。

### 分界
- 与 DETAIL"事件排序"(D-04):本质同考"顺序",但本题型是**①~④ 序列选项**的标准中考形式;D-04 的 `What is the correct order?` 已是同族。
- 前提硬约束:原文必须有明确时间标记/序列词,否则不出排序题(排序题最忌靠逻辑猜)。

| 题型 | 数量 | 说明 |
|------|------|------|
| DETAIL | 2 | 基座,保底得分 |
| MAIN IDEA | 1 | 全篇/段落理解(标题/主旨/目的选一) |
| VOCABULARY | 1 | 词义或指代选一 |
| 第五题轮换 | 1 | INFERENCE / VOCABULARY / MAIN IDEA 按课文特点选 |

轮换原则:第 5 题优先补 INFERENCE(区分度)或 VOCABULARY(最实用);次选 MAIN IDEA(段落目的/提及意图)。难度阶梯:先细节后推理,INFERENCE 常压轴。

> 注:原 8 类/6 类分类中 GIST、PURPOSE 已并入 MAIN IDEA;REFERENCE 代词指代已并入 VOCABULARY。如用户沿用旧体系,可按子模式单独抽取,两种分类并存不冲突。
