# 阅读理解命题 · 出题逻辑操作系统

> 「出题不是选对的那个,是造出三个看起来都对、但只有一个对的。」—— Reading Explorer 命题体系的核心信仰

## 我能帮你的 / 我不能帮你的

**我能帮**:给定文章出阅读题(选题型→设计题干→构造干扰项)、按教材体规范审校已有题目、讲题型逻辑、归类型分界
**我不能帮**:保证文章本身的命题合规(词汇覆盖率/超纲词/句长请调 vocab-checker 与 zhongkao-mcp 校验)、替代你的考点优先级判断

## 执行规则（最重要）

**此Skill激活后，按以下流程执行。不同场景走不同路径。**

### 场景A: 给一篇文章 → 出阅读题

```
Step 1: 定体例 + 考点分布
  → 先判断体例(决定整卷题位):
     - 用户明确说"教材体/中考作业体" → 按用户说的
     - 用户没说 → 按素材特征判定:首段有明确开篇手法(提问/场景/故事/举例/数字/对比)**且**文中有清晰时间标记/序列词 → 默认中考作业体;缺任一 → 教材体(见 Fallback #11/#12)
     - 【判据例证】"清晰时间标记/序列词"指**能构成事件先后链的词**:"first/then/after/later/in the past/Today"等时间副词**且**文中至少 3 个按时间排列的事件。只有泛时间词(past/Today 单现)或只有数字(quarter/60%)而无事件链,**不算**。注意:开篇手法清单里的"数字"指**首段以醒目数字开篇**(如 "60% of the students..."),出现数字≠就是数字开篇手法——`quarter` 在句中作普通数量词不算。
  → 定整卷题型组合(约 5 题/组)
  → 教材体典型配置:2 DETAIL + 1 MAIN IDEA + 1 VOCABULARY + 1 轮换(INFERENCE / VOCABULARY / MAIN IDEA)
     - 【默认题序】教材体按 D·D·I·M·V 排列(DETAIL×2 在前,INFERENCE 中段,MAIN IDEA 近尾,VOCABULARY 收尾);若轮换位选 M 或 V,则与 MAIN IDEA/VOCABULARY 互换,保证两个 MAIN IDEA 不连排
     - 【轮换位决策】轮换项在卷面排第 3 位(前 2 DETAIL 之后),优先"补全未覆盖题型":已覆盖 INFERENCE 则选 M 或 V 中更能拉开难度的;未覆盖则按 I→M→V 顺序选
  → 中考作业体典型配置(Q1-Q5):写作手法·开篇引入 + 2 细节/推断 + 排序·事件顺序 + 主旨/标题
  → 【检查点】先给出"体例判定依据 + 题型清单 + 每题考哪个点(从文章哪句出)",快速模式给一行,确认模式停一下等用户确认

Step 2: 选题型
  → 对照 question-type-library.md 各题型子模式
  → 每个考点选一个子模式(例:考点"章鱼变色机制"可选 DETAIL 正向事实 或 INFERENCE 应用迁移)
  → 子模式冲突时选"最能考到学生真实理解"的那个
  → 【检查点】每个子模式能说清"选它考什么、对应文章哪句、为什么比其他子模式好"吗?说不出 = 重选

Step 3: 设计题干
  → 按所选子模式的题干模板写(见 question-type-library.md 每类模板)
  → 题干必须指向"唯一的考点",不含多余信息、不暴露答案
  → 【检查点】去掉题干里任一关键词,考点还唯一吗?有多余信息吗?读题干能推出答案吗?任一"是"= 重写

Step 4: 构造选项
  → 正确项:严格源自原文(零推理=原文可查;推理=推导一步可得)
  → 干扰项:按该类干扰项手法构造(见 design-logic.md),每个干扰项必须"看似合理但有明确排除依据"
  → 【模具判定信号】"部分正确"与"字面误读"边界重叠时,用信号区分:选项前半真后半假/主谓错配=部分正确;选项逐字截取原文片段但答非所问=字面误读。一题内优先让干扰项覆盖**不同**模具,避免同质
  → 【检查点】每个干扰项过一遍排除依据:字面误读?过度推断?张冠李戴?未提及?部分正确?都答不出就重做
  → 【检查点】答案字母分散(A/B/C/D 不连选 3 次以上)、选项长度均衡(正确项不显著偏长)

Step 5: 自检交付
  → 交付时附"每题:题型 + 考点出处 + 正确项依据 + 各干扰项排除依据"
  → 【强制校验】交付前调用 `mcp__zhongkao-mcp__validate_questions`(questions 每项含 id/stem/options/answer/type,option_count=选项数)校验选项格式、答案唯一性、题型覆盖;有 fail/review_required 则修正后重跑,直至 all_pass。**type 字段必须用 validator 认的小写命名**,不能直接用本 Skill 的展示名:**DETAIL→`detail`、INFERENCE→`inference`、MAIN IDEA→`main_idea`、VOCABULARY(含指代类 REFERENCE)→`vocabulary_or_detail`、写作手法→`writing_technique`、排序→`ordering`**(大写/展示名会触发 type_coverage 报"题目类型可能缺失";`detail` 也可用,validator 视其为 vocabulary_or_detail 的同类别名)。MCP 不可用时退化为人工自检:逐题复核①答案字母在选项范围内②无两个可答项③**答案字母指向的选项文本 = 写定的正确项**(字母与正确项内容错位=出题事故,必须重写选项或改字母;MCP 只查字母范围、查不出内容错位)
```

### 场景B: 分析一道题怎么出的

```
Step 1: 判定题型
  → 读题干,按 question-type-library.md 特征词匹配题型
  → 特征词示例:DETAIL=Which is true/Why did/How many;INFERENCE=probably/would X agree/can we definitely say
  → 拿不准 → 用 design-logic.md 的类型分界(如 DETAIL 与 INFERENCE 的零推理/一步推导分界)
  → 【检查点】判定必须挂证据:说"这是 INFERENCE"要指出题干哪个词表明要推导;说"这是 MAIN IDEA"要指出是内容问法还是功能问法

Step 2: 拆解构造
  → 分析:题干指向哪个考点、正确项来自原文哪里、每个干扰项用了什么手法
  → 标注干扰项手法:字面误读/极端化/张冠李戴/未提及/部分正确
  → 【检查点】每个干扰项都标了模具吗?正确项能否指认原文出处?标不出 = 分析没到位

Step 3: 评价
  → 【检查点】给出质量判断:考点是否清晰?干扰项是否都有排除依据?有无歧义?
  → 如题目有缺陷,给出改法
```

### 场景C: 审校/改写已有题目

```
Step 1: 逐题过检
  → 用 design-logic.md 反模式清单逐项过,标记命中的
  → 检查:题干是否指向唯一考点、正确项是否严格源自原文、干扰项是否都有排除依据、选项格式是否规范
  → 【检查点】每题至少能标注一个明确问题或明确"达标";只写"还行"没列具体问题 = 审校不达标

Step 2: 给出诊断
  → 【检查点】先列问题清单(每条:题目位置+问题+改法),用户确认要改哪些

Step 3: 改写
  → 只改用户确认的问题,不重写全部选项
  → 保留原题考点方向,除非用户要求换题型
```

## 🛑 STOP · 关键 CHECKPOINT

### 场景 A · 出题前必答 3 问
1. **题型选对了吗**（对照子模式,不是凭感觉）?说不出依据 = 重新选
2. **题干锁死唯一考点了吗**（去掉任一关键词考点还唯一?有冗余信息?）?没锁死 = 重写题干
3. **正确项有原文依据吗**（零推理=可查原句,推理=推导步骤写得出）?没有 = 这题出得没根
4. **每个干扰项都有排除依据吗**（字面/极端/张冠李戴/未提及,至少占一个）?没有 = 这题在猜
5. **答案字母指向的选项文本 = 写定的正确项吗**（字母与内容错位=事故,哪怕内容本身正确也算错）?不一致 = 重写选项或改字母

### 场景 B · 分析前必答 2 问
1. **题型判定挂证据了吗**?说"这是INFERENCE"要指出"题干哪个词表明要推导"
2. **每个干扰项的手法都标注了吗**?只标对错 = 没分析到出题手法

### 场景 C · 改写前必答 2 问
1. **先给诊断后改写了吗**?用户没确认问题清单 = 别动
2. **反模式对照了吗**?至少把 W1-W10 过一遍

任一答「否」→ 回到对应 Step。

## 失败模式与 Fallback 树

| # | 触发信号 | 第一选择 | 备用 |
|---|---------|---------|------|
| 1 | 文章太短(考不了 5 题) | 减题量,优先保留 DETAIL + INFERENCE | 合并考点,一题考两处 |
| 2 | 一个考点命中多个题型 | 选"考理解深度"最高的那个 | 让用户选,展示两种题干的差异 |
| 3 | 选项凑不满 4 个干扰项 | 补"未提及但看似合理"型干扰项 | 用 3 选项(教材少数题目 3 选项,但需用户确认) |
| 4 | 正确项拿不准是否忠实原文 | 回原文逐词核对 | 明说"这题正确项需回原文验证",不硬出 |
| 5 | 用户要严格命题合规(中考词汇) | 出题后提示调 vocab-checker 校验,不自行承诺达标 | 出题时就选高频词作考点词 |
| 6 | 用户说"题太简单/太难" | 太简单→换 INFERENCE/VOCABULARY 子模式加深;太难→换回 DETAIL/MAIN IDEA | 调整题干复杂度(信息量/句长),不动考点 |
| 7 | 用户说"不是这种风格" | 问清参考哪套教材风格 | 默认按 Reading Explorer 体(题干简洁、3-4 选项) |
| 8 | 用户只要题目、不要解析 | 只交付题干+选项+答案,省略考点出处/干扰项排除 | 确认是否连答案都省略(纯练习卷) |
| 9 | 文章是中文/双语 | 出英文题但用中文注解考点依据 | 问用户要全英文出题还是中英混合 |
| 10 | 素材太短(1-2 句) | 减到 2-3 题,优先 DETAIL + INFERENCE | 明确告知该素材撑不起 5 题 |
| 11 | 素材没有清晰时间标记/序列词 | 不出排序题(Q4 换 INFERENCE/MAIN IDEA) | 排序题最忌靠逻辑猜,宁可换题 |
| 12 | 首段无明确开篇手法 | 不出写作手法题(Q1 换 DETAIL) | 写作手法必须能指认首段实际手法 |
| 13 | 用户没提供文章原文就要出题 | 说明需原文才能保证考点对应,先出「题型框架」级示例 | 请用户贴原文后再正式出题 |

## 反例黑名单(绝不要做)

| # | 反模式 | 为什么禁 | 正确做法 |
|---|--------|----------|----------|
| W1 | 正确项直接抄原文整句(DETAIL 除外) | 出的是"认字"不是"阅读" | 需要加工:转述、概括、替换表达 |
| W2 | 干扰项无排除依据 | 选项在靠运气 | 每个干扰项必须可指认一个明确错误(见场景A Step4) |
| W3 | 题干含多余信息或暗示答案 | 泄题 | 题干只给解题所需信息 |
| W4 | INFERENCE 干扰项带绝对词(all/never/must) | 绝对化 = 自动排除,送分 | 干扰项设计为"看似合理但证据不足",不是"一眼假" |
| W5 | VOCABULARY 考字面常见义 | 没考语境理解 | 考本语境义(例:average 考"typical"而非"smart") |
| W6 | 指代对象超出段落语境 | 指代对象不在本段 | 指代对象必须在本段可定位 |
| W7 | MAIN IDEA 内部问法混淆 | 标题/大意、段落主旨、目的/提及意图混用 | 标题=内容、main idea of paragraph=段落论点、purpose/mention=功能 |
| W8 | 句意题正确项几乎同词 | 正确项与原文同词 | 正确项换表达,考"实际含义 vs 字面含义" |
| W9 | 一道题题干可指向多个答案 | 出题事故 | 题干锁定唯一考点(见场景A Step3) |
| W10 | 为了凑题量硬造考点 | 题是空的 | 出不了就减题,不硬凑 |
| W11 | 答案字母与正确项内容错位 | 答案标 X 但 X 项内容是干扰项、正确项内容在 Y 项 | 逐题复核:字母指向的文本 = 写定的正确项;不一致即重写选项或改字母 |

## 诚实边界

1. **来源局限**:方法归纳自 Reading Explorer Level 1 两册(第三版 + 第二版)的 233 道 Reading Comprehension 题 + 3 篇中考英语作业题(写作手法/排序题型来源);其他教材/年级的题型分布与手法可能不同
2. **分类非穷尽**:4 题型 + 2 新题型是"读出来的规律"而非唯一真理;题目可以杂交(如 MAIN IDEA 目的问法中掺 INFERENCE 色彩),题型是脚手架不是牢笼;原 8 类的 GIST/PURPOSE 已并入 MAIN IDEA、REFERENCE 指代已并入 VOCABULARY,如用户沿用旧体系可再拆分
3. **写作手法/排序题位固定**:这两种题型来自中考英语作业题(非 RE 教材),固定 Q1/Q4 题位,按用户提供素材的出题风格定
4. **无法保证命题合规**:词汇覆盖率/超纲词/句长需用 vocab-checker、zhongkao-mcp 实测
5. **出题忠于素材**:基于用户提供的文章出题,不凭空给原文没有的信息作正确项
6. **正确项依赖原文**:需要我出题时,请提供文章原文;没有原文只能出"题型框架"级示例,不能保证考点对应

**调研时间**:2026年8月5日(更新:重新分类为 4 类,PURPOSE/GIST 并入 MAIN IDEA,指代并入 VOCABULARY;新增写作手法/排序两题型)
**调研来源**:Reading Explorer Level 1 两册共 233 道 Reading Comprehension 题(MinerU 从 PDF 提取,已按 4 类归类入 4 个 docx)+ 3 篇中考英语作业题(写作手法 3 题 + 排序 3 题,来源 `Downloads\写作手法和排序\`),详见 `references/research/`
